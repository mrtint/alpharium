# G4 자동 쓰기 설정 창 — 설계

입력: `docs/user-guidance-rules.md` 0장 D2·D5·U1, 0-1 흐름도, 0-4 G4 행.

## 목적

첫 실행이 끝난 뒤 한 창에서 「자동으로 쓰기」·쓰는 시각·배터리 예외(안드로이드)를 정하게 한다. 첫 실행 권한 단계의 배터리 화면을 걷어 권한 단계를 모두 「스플래시 + OS 창」으로 통일한다.

## 결정

| 결정 | 근거 | 뒤집으면 바뀌는 것 |
| --- | --- | --- |
| 새 설치에만 띄운다 | 소유자(2026-11-25) | 기존 사용자 이행 플래그 필요 |
| 대기 플래그 `autoWriteSetupPending`을 `preferences/onboarding.json`에 둔다(첫 실행 시작 때 true, 「켜기」/「나중에」에서 false) | 첫 일기 전 앱이 죽어도 다음 실행에 묻는다 — 배터리를 묻는 곳이 사라지지 않게 | 메모리 판정만이면 놓칠 수 있다 |
| 띄우는 조건: 플래그 true · `firstDiary.step === "done"`(또는 첫 일기 흐름이 이번 실행에 돌지 않음) · 쓰는 중 아님 · 다른 확인 질문 없음 | 0-4 G4, R8 | — |

## 수용 기준

1. 새 설치 첫 실행 권한 단계에 배터리 화면이 없다(`requirements.ts`에서 `battery-exception` 제외 — 설정 화면 권한 행 쓰임은 확인 후 유지/조정).
2. 첫 일기 흐름이 끝나고(저장·실패·나중에·재료 없음·건너뜀) 쓰는 중이 아닐 때 설정 창이 한 번 뜬다. 쓰는 중에는 뜨지 않는다.
3. 창: 제목 「매일 일기를 써 드릴까요?」, 행 「자동으로 쓰기」·「쓰는 시각」·(안드로이드)「배터리 제한 풀기」, D5 조건 줄(플랫폼별), 버튼 「켜기」/「나중에」.
4. 「켜기」는 설정 화면과 같은 저장 경로로 토글·시각을 저장한다. 「나중에」는 아무것도 바꾸지 않는다. 둘 다 플래그를 지워 다시 뜨지 않는다.
5. 기존 사용자(플래그 없음)에게는 뜨지 않는다.
6. 함께 걸린 문구(슬라이드 3 제목·권한 설명·스토어 설명문)는 K4대로 「켜 두면」 조건을 품는다. 골든은 `CHANGED_AFTER_GOLDEN`.
7. 규칙 문서에서 G4 행과 끝난 전수 목록 행을 지운다.

## 시험

순수 판정 함수 단위 테스트, 창 렌더 테스트, 온보딩 단계 목록, 문구 계약. 실기기: 안드로이드 배터리 설정 왕복, 쓰는 중 미표시.
