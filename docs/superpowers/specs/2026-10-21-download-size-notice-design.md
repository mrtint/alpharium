# 첫 실행 다운로드 크기 공지 — App Store 4.2.3(ii) (설계)

- 로드맵: 「첫 실행 다운로드 크기 공지 — App Store 4.2.3(ii)」(출시 준비 C1, `docs/roadmap/release-readiness-analysis.md`)
- 날짜: 2026-10-21
- 결정: 소유자가 045 FR-003(표준 동의에 용량 비노출)을 뒤집는 것을 승인했다(2026-10-21). 세부 선택은 소유자가 「특별한 이견이 없으면 추천대로」로 위임했다.

## 목적

App Store 심사 지침 4.2.3(ii)는 첫 실행에 추가 자원을 받아야 하면 **받을 크기를 알리고 먼저 물으라**고 한다. 지금 표준 동의(Wi-Fi·연결 모름)는 「먼저 묻기」는 하지만 받을 양을 보이지 않는다 — 045 FR-003에서 일부러 정했고, 074 뒤로는 모바일 데이터일 때만 양이 보인다. 이 빈자리를 닫는다.

## 헌법 검토 — 개정 불필요

- 원칙 IV는 2.0.0 개정에서 「다운로드 상태 표시」를 금지 대상에서 명시적으로 뺐다.
- 원칙 III이 막는 것은 모델 식별자·파라미터 수·양자화 등 내부 사양이다. 「약 2.0GB」는 받을 양이지 모델 사양이 아니며, 074 모바일 동의와 058 설정 「이 휴대폰」이 이미 보인다.
- 용량을 숨긴 근거는 헌법이 아니라 045 스펙 FR-003이다 → 이 기능이 그 FR을 대체한다.

## 결정

1. **표준 동의 본문에 받을 양을 넣는다 (안 A)**: 「일기를 쓰려면 사진을 읽는 모델과 글을 쓰는 모델을 약 {size} 내려받아야 해요. 한 번만 받으면 이후로는 필요 없어요.」 — 바뀌는 곳이 가장 적고 모바일 동의의 「약 {size}」와 표기가 같다. Wi-Fi 권고는 넣지 않는다(연결 모름의 대부분은 Wi-Fi이고, 넣으면 074가 가른 두 동의가 같은 말을 한다).
2. **양을 못 읽으면 지금 문장 그대로**다(원칙 V — 양을 지어내지 않는다). 양 문자열은 074의 `readSizeLabel`(남은 바이트 → `formatModuleBytes`, 1000 기준)을 그대로 쓴다 — 새 계산을 만들지 않는다. 이어 받기면 남은 양이 보인다(074와 같은 값).
3. **버튼은 [받을게요] 하나 그대로**다(045 FR-002a 유지). 4.2.3(ii)는 알리고 묻기까지만 요구한다.
4. **연결 종류와 받을 양을 동시에 읽는다.** 각자 한도 3초(`READ_LIMIT_MS`)는 그대로다. 차례로 읽으면 표준 동의가 최대 6초 빈 화면이 된다. 동시에 읽으면 최악 3초로 지금과 같다.
5. **표준 동의 화면은 양을 prop(`sizeLabel: string | null`)으로만 받는다** — `CellularConsentDialog`와 같은 모양. 화면은 모듈 자산·연결 조회에 닿지 않는다(045 C9의 「`essential-assets` import 금지」는 유지). 문구는 카탈로그 함수 `body(size)`로 둔다.
6. **문구 골든**: 062 골든은 다시 쓰지 않는다. 양이 든 새 문장은 `ADDED_AFTER_GOLDEN`에 올리고, 양 없는 원래 문장은 못 읽을 때 그대로 쓰이므로 골든에 남는다(074 모바일 본문과 같은 처리).
7. **Play 심사 메모(W7)**: 저장소에 심사 메모 문서가 아직 없다 — 이 기능은 만들지 않는다(W7은 Play 출시 과제 몫). 설계에 같은 문구를 쓴다는 것만 남긴다.

## 확인

- 단위·계약: 위 테스트 + `npm test`·`npm run lint`.
- 위반 주입: 화면이 양을 못 읽었을 때 지어낸 값을 넣으면(예: 기본 「2.0GB」) 테스트가 잡는다.
- 실기기(dev): Wi-Fi 첫 실행 동의 화면에 「약 2.0GB」가 보인다. 이 세션은 클라우드 컨테이너라 기기가 없다 — 소유자 확인으로 남긴다(원칙 V: 건너뛴 실기기 테스트는 통과가 아니다).

## 위험

- 045 계약이 소스 어휘까지 묶었다(`GB` 금지 정규식). 그 단언을 지우면 모델 식별자 금지까지 같이 약해질 수 있다 → 식별자·자산 키 금지는 남기고 `GB`·`byte`만 뺀다.
- 「약 2.0GB」는 남은 양이라 이어 받기에서 작게 보인다 — 074와 같은 정의라 받아들인다.
