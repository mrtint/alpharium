# Quickstart — 092 실기기

전제: iPhone 14(iOS 27.0.1) 무선 연결, **충전기·선 없음**, 개발 환경 Release 빌드 설치(새 네이티브 모듈 — prebuild 필요).

1. 사진 있는 안 쓴 날을 고른다(091 시드). 홈에서 「쓰기」 → 5초 안에 홈 화면으로 나간다.
2. 잠금 화면·알림 센터의 진행 표시를 본다(단계 문구, 막대가 움직이는가).
3. 완성 알림을 기다린다. 앱 컨테이너의 `Documents/diary/<날짜>.json`, `systemCrashLogs`의 `cpu_resource_fatal`을 읽는다.
4. 같은 절차를 앱에 머문 채 한 번(SC-003 시간 비교), 쓸 차례 알림 누름으로 한 번.
5. 이어 쓰는 중 진행 표시에서 취소 → 「도중에 끊김」 기록·앱 생존.
