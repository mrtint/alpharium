# `src/app/` — 사용자 경로의 조립

**여기가 사용자 경로를 조립하는 유일한 자리다.**

001의 `config/policy.ts`가 원칙 I의 방어선을, 003의 `models/roster.ts`가 원칙 III을,
005의 `diary/prompt.ts`가 원칙 II를 한 곳에 모은 것과 같은 구조다.

## 왜 이 자리가 필요한가

006 이전에는 조립할 자리가 없어 `App.tsx`가 직접 했고, `GenerationProbe`는 아예
어댑터를 직접 불러 **저장을 건너뛰었다**. 그것이 일기가 하나도 남지 않은 원인이다.

## 여기서 지키는 것

- **`wiring.ts`** — 추론 어댑터는 `inference/select.ts`에서만 온다(FR-026). 저장소는
  `diary/store.ts`의 `fileStore`. 이 둘을 파이프라인에 묶는 곳이 여기 하나뿐이어야
  「사용자 경로가 저장까지 가는가」를 기기 없이 검증할 수 있다(SC-008b, SC-024).
- **`state.ts`** — 화면 상태 전이. **순수 함수로 둔다**(SC-023). 기기 없이 전 갈래가
  검증되어야 하기 때문이다.

## 여기에 두지 않을 것

- 화면 컴포넌트 — `src/ui/`의 몫이다
- 추론 위치 판단 — `inference/select.ts`가 한다. 여기서 다시 고르면 방어선이 갈라진다
- 생성 시간·속도·토큰 수 — 원칙 IV
