# 105 실기기 확인 기록

## 상태: 못 했다 (2026-10-26)

착수 세션에서 `adb devices`가 비어 있었다 — SM-S901N이 연결되어 있지 않았다. **건너뛴 실기기 확인은 통과가 아니다**(헌법 원칙 V). 이 기능은 기기 불필요 테스트로만 검증됐다.

## 해야 할 확인 (quickstart.md)

1. dev(debug) 빌드, `adb reverse tcp:8081 tcp:8081`. 자동 쓰기 켬, 목표 시각 창 안.
2. `sample:seed`로 어제에 표본 사진(`seed:day` 템플릿 1×1은 VLM이 자주 실패한다), 오늘은 사진 없음.
3. 앱을 열기 → 홈이 어제를 「쓰는 중」으로 합류하고 저장되는가.
4. 개발자·진단 「최근 자동 쓰기 시도」에 「앱 열기 · 홈에 넘김 · 어제 날짜」가 남는가(`run-as com.a810labs.pocketlog`로 `files/preferences/auto-write-attempts.json`의 `day`도).
5. 가능하면 `cmd jobscheduler run -f`로 백그라운드: 어제가 써지고 완성 알림, 기록 줄 `ran` + `day`.
6. 헤드리스에서 후보 3일치 미리보기 조회가 시간 예산에 부담이 되는지 본다(측정하지 않은 가정).
