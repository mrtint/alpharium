# 자동 쓰기 규칙 — 설계

- 날짜: 2026-10-02
- 입력: [설정·개발자 분해 설계](2026-10-01-settings-developer-decomposition-design.md) §3.3 (S11·S13, D1~D4, 앞 문서 C1~C9)

- 보드: `C:\Users\mrtin\Downloads\mdesign\Alpharium Mobile Screens.dc.html`의 `6c` ③(동작 메모)·`6g`·문구표 `notif.autoWriteDone`

## 목적

자동 쓰기가 「재료가 관측된 0인 날」과 「사진 권한이 없는 날」을 쓰지 않는다(지어 쓰기는 사용자가 직접 확인할 때만, 053 `2f`).
사진 권한 때문에 건너뛴 사실을 설정의 사진 행 아래에 한 줄로 남긴다(`6g`). 목표 시각이 지난 뒤 앱을 열면 홈이 쓰는 중(054 `2b`)으로
시작한다. 완성 알림을 이름과 날짜가 든 한 줄로 바꾼다.

## 보드 원문

- `6c` ③ — 그날 일기가 이미 있으면 건너뜀. 재료가 0이면 자동으로는 쓰지 않음(지어 쓰기는 2f 처럼 직접 확인할 때만). 사진 권한이 없으면 건너뛰고
  사진 행에 표시( 6g ). 그 시각이 지난 뒤 앱을 열면 홈이 쓰는 중( 2b )으로 시작. 다 쓰면 알림 한 번(알림 권한이 있을 때만) — 누르면 2c .
  끈 상태에선 홈의 "일기 쓰기"로만 씀.
- `6g` — 사진 권한이 없어 자동 쓰기를 건너뛴 날이 있으면 사진 행 아래에 빨간 보조 문구 한 줄 — "어제 자동 쓰기를 건너뛰었어요"(그 전이면
  "9월 11일 자동 쓰기를 건너뛰었어요"). 가장 최근 한 번만 표시. 권한을 허용하고 돌아오면 문구가 사라지고, 건너뛴 날은 홈에서 그 날을 골라 직접
  쓸 수 있음. 알림은 보내지 않음.
- 문구: `perm.photos.skippedYesterday` 「어제 자동 쓰기를 건너뛰었어요」 · `perm.photos.skippedOn` 「{M}월 {d}일 자동 쓰기를 건너뛰었어요」 ·
  `notif.autoWriteDone` 「{name}{이|가} {M}월 {d}일 일기를 다 썼어요」.
- `6g` 마크업: 보조 줄이 있는 사진 행은 최소 높이 56, 라벨과 보조 줄 사이 3, 보조 줄 12 · 줄높이 1.35 · `accent-700` · 낱말 단위 줄바꿈.
  055 행의 `hint`와 같은 자리·크기이고 색만 다르다.

## 구성

- **`src/schedule/auto-write.ts`(순수)** — `decideAutoWrite({ schedule, material })` → 쓴다(그 날) / 건너뛴다(이유: 재료 0 · 사진 권한 없음) / 돌 일 없음.
  053의 `decideMaterial`·`fromCountHint`를 쓴다(`src/schedule/`→`src/app/` import는 `task.ts`가 이미 `app/wiring`으로 하고 있다 — 계층은 plan에서 확정).
- **`src/schedule/skip-store.ts`(+ 기기 통로)** — 건너뛴 날 하나를 읽고·쓰고·지운다. 시각·건수·이유 문자열을 담지 않는다(D3, 020 S7).
- **`task.ts`** — `decideSchedule` 통과 뒤 그 날의 미리보기(048 `previewDay`와 같은 신호 통로)를 읽고 `decideAutoWrite`로 가른다. 사진 권한 건너뜀이면
  기록을 남기고 알림 없이 `"skipped"`.
- **알림** — `notification-port.ts`의 고정 제목을 `notif.autoWriteDone` 한 줄로 바꾼다. 이름은 035의 지금 이름, 날짜는 쓴 날. 조사 「이/가」는 받침으로 가른다(순수 함수).
- **앱을 열 때** — 조립부(`App.tsx`)가 마운트·전경 복귀 때 판정해 홈에 「자동으로 쓸 날」을 넘기고, 홈은 그 날을 고른 날로 두고 쓰는 중에 들어간다
  (재료 확인 대화상자를 거치지 않는다 — 이미 판정했다). `AppState`는 「다시 볼 때」의 신호일 뿐 판정 입력이 아니다(AGENTS).
- **설정 사진 행** — 055 행에 빨간 보조 줄 하나. 「어제/M월 d일」 표기는 순수 함수(`now`를 인자로).
