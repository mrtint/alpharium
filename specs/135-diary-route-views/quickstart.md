## iOS 시뮬레이터(모양)

1. 표본 사진(`npm run sample:seed` 계열 — 좌표 있는 사진이 둘 이상 자리)을 심은 시뮬레이터에서 dev 빌드로 쓴 날을 하나 만든다.
2. 쓴 날: 캐러셀 우측 하단 지도 아이콘 → 지도 면(아래 글 위치 그대로) → 갤러리 아이콘 → 사진 면.
3. 지도 면에서 번호 → 카드(사진·「번호 · 이름 · 때」) → 카드 → 그 자리 사진만 확대.
4. 옛 일기(135 이전에 쓴 날)에서 번호 → 「이 일기에는 자리별 사진이 남아 있지 않아요」.

## 실기기(동작)

- iPhone 14·SM-S901N dev 빌드에서 위 2·3을 손으로 확인하고, 저장된 일기 JSON의 `photos[].placeIndex`를 읽는다(안드로이드 `run-as`).

## 기록

**2026-11-26, iOS 시뮬레이터(iPhone 17, iOS 27.0, dev 번들 — 온디바이스 쓰기)**

- 11-20에 좌표 사진 다섯 장(서울숲 9·10시, 성수 13시, 좌표 없음 15시, 강남 18시)을 `simctl addmedia`로 심고 홈에서 「일기 쓰기」로 새로 썼다. 저장된 `photos[].placeIndex` = `[0, 0, 1, null, 2]`, `places` = 서울숲(2)·성수역(1)·강남역(1) — 기대대로.
- 사진 면 우측 하단 지도 아이콘 → 지도 면(같은 자리, 아래 글 위치 그대로) → 1번 점 → 폴라로이드(사진 2장 겹침, 「1 · 오전 · 서울숲」) → 카드 → 확대 화면 「1 / 2」(그 자리 사진만).
- 옛 일기(11-21, 135 이전)에서 1번 점 → 「이 일기에는 자리별 사진이 남아 있지 않아요」(카드는 점 옆자리).
- 다른 날을 골랐다 돌아오면 사진 면으로 시작.

**못 본 것**: 실기기(iPhone 14·SM-S901N) 동작 — 실기기 화면은 도구로 누르지 못하고, 안드로이드는 이번에 adb에 연결돼 있지 않았다. 동작 줄이기·VoiceOver 낭독(카드 알림)·글꼴 2.0배·작은 화면.
