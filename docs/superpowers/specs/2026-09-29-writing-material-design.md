# 쓸 재료 — 설계

- 날짜: 2026-09-29
- 입력: `2026-09-26-home-uiux-decomposition-design.md` §3.3 + 보드 원본 마크업 재대조
  (`mdesign.zip` → `Alpharium Mobile Screens.dc.html`, `1d`·`2l`·`2m`·`2e`·`2f`)
- 범위: 안 쓴 날의 「쓸 재료」 칸, 권한 없음 표시와 요청, 쓰기 전 확인. 「제자리 쓰기」(2b·2i)는 범위 밖.

## 다시 만들지 않는 것

| 이미 있는 것 | 쓰는 방식 |
| --- | --- |
| 050 `ConfirmDialog`·`DialogActionButton`·`DialogCancelButton` | `2f`(재료 없음 확인)와 `2m`(설정 열기) — 보드에서 `2d`와 마크업이 같다 |
| 048 `previewDay`·`DayPreview`·`toDayPreview` | 세 갈래(`known`·`none`·`unknown`) 그대로. 「권한 없음」 갈래만 더한다 |
| 051 하단 바(`WriteBar`) | 이미 보드대로(날짜 조각 없음). 누름의 행동만 바뀐다 |
| 021 `requestPhotoPermission()`, `os-settings-port` | 권한 요청·설정 열기 통로 |

## 바꾸는 것

1. **신호 줄** — 세 칸을 두 칸(사진·장소)으로. 「쓸 수 있는 때」 칸·칸 사이 세로선 제거, 「다닌 자리」→「장소」.
   숫자 48/800·단위 15/700, 0은 숫자만 보조색, 아래 1px 구분선. 지면은 화면 바닥까지 채우고 스크롤 없음.
2. **`2l` 권한 없음** — 사진 권한이 없어서 셀 수 없을 때 숫자 대신 빨간 「권한이 없어요 ›」(높이 44).
   읽기 실패는 이 문구를 쓰지 않는다(원칙 V). 이를 위해 `CountHint`에 「권한 없음」 갈래를 더한다.
3. **`2m` 요청** — 탭하면 사진 권한 요청. `canAskAgain === false`면 `ConfirmDialog`
   「설정에서 사진 접근을 허용해 주세요 / 설정 열기 / 취소」. 허용·복귀(`AppState active`) 시 다시 센다.
4. **`2e` 재료 0** — 0/0이면 아래에 「기록 대신 상상으로 하루를 채워요.」(위 간격 14 = 컬럼 gap 6 + 8).
5. **`2f` 쓰기 전 확인** — 순수 함수 하나가 조건표로 판정한다: 셀 수 있는 항목에 재료가 하나라도 있으면 바로 쓰기,
   셀 수 있는 항목이 모두 0이거나 전부 권한 없음이면 확인 후 쓴다. 배경 탭으로 닫히지 않고, 취소는 닫고 화면 유지.
6. **「지어낸 하루」 표식** — 다 쓴 일기에 남긴다. 표시 방법은 clarify에서 정한다.

## 보드 마크업에서 읽은 시각 사항

- 지면: `flex:1`·`gap:6`·안쪽 여백 20 20 120, 배경 `neutral-100`, 스트립과의 간격 20.
- 안내 한 줄: 14, 줄높이 1.5, 보조색, 위 간격 = gap 6 + margin 8.
- 권한 없음 셀: 가운데 정렬, 16/700 + `›` 18/700, 간격 6, 높이 44(`2m`의 41은 보드 내부 불일치 — 메모 44를 따른다).
- `2f` 대화상자: `2d`와 동일(2px 테두리·여백 24·간격 16·버튼 48/반경 6, 확인 위·취소 아래).
- 바: 안드로이드는 하단 안전 영역을 쓴다(보드의 34는 iOS).

## 열려 있는 결정(clarify)

1. 「장소」의 권한을 무엇에 묶을지 — 장소 수는 사진 EXIF에서 나와 사진 권한이 없으면 장소도 셀 수 없다.
2. `unknown`의 두 이유(권한 없음·읽기 실패)를 화면에 어떻게 보일지.
3. 「지어낸 하루」 표식의 자리와 저장 방식.
4. `2f` 제목 「😢 아무 기록도 없어요」가 「전부 권한 없음」일 때 거짓이 되는 문제.
5. `2e` 안내 한 줄이 보이는 조건(한쪽 0 + 한쪽 권한 없음, 전부 권한 없음).
6. 「쓸 수 있는 때」 칸 폐지(049로 정오 제한이 없어져 무해하다고 본다), 048 후속 메모 2번(기록 부족 안내)을 이 조각이 닫는지.
7. 「권한이 없어요」 글자 색 — accent 대비가 4.5:1에 못 미쳐 `danger`를 검토.
