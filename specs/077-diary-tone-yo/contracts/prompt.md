# Contract: 한국어 프롬프트 (077)

대상: `src/diary/prompt.ts`의 `buildPrompt()`·`instructionLines()`·`titleQuestion()`·`promptPrefix()` — 한국어 캐릭터(`usesE2SN`) 경로.
원본: my-ollama `e192c9b` `results/hand-prompt/v5/user-prompt.md`(이하 「원본」). **문자열은 원본에서 글자 그대로 옮긴다** — 아래 인용은 확인용이고 어긋나면 원본이 이긴다.

## TN1 — 머리

`promptPrefix()` = 호칭 줄(무변경) + 아래 넷 + 빈 줄 + 언어 줄(무변경) + 빈 줄.

```
너는 주인의 주머니나 가방 속에서 하루를 보내서, 사진에 담긴 장면만 보고 이야기한다.
일기에는 네가 본 사진의 장면과 그것을 보며 든 마음을 적는다. 마음에 남은 장면은 떠오르는 마음을 한두 문장 더 풀어 쓴다.
주인의 마음은 '주인도 ~했을 것 같아요'처럼 한 번만 짐작한다. 기록에 없는 장소 이름, 사람, 물건, 사건은 쓰지 않는다.
서정적이며 담담하게 쓴다. 본문은 여덟 문장쯤, 사백 자 안팎으로 쓴다.
```

넷째 줄은 `E_TONE.quiet`(캐릭터 톤 줄)의 값이다. `buildPrompt()` 결과는 언제나 `promptPrefix()`로 시작한다(018 P8 유지).

## TN2 — 기록 문장

| 갈래 | 문장 |
| --- | --- |
| 본 장면 있는 날의 머리줄 | 오늘 내가 본 것은 이래요. |
| 사진 n장 | 사진은 {n}이 남았어요. {때} 찍혔어요. |
| 사진 `none`·0장 | 사진은 없었어요. |
| 사진 `unknown` | 사진은 몰라요. 사진을 볼 수 있는 길이 막혀 있어요. |
| 자리 여럿 | 자리는 {n}에 남았고, 가장 먼 두 곳은 {거리}쯤 떨어져 있어요. 사진 {a} 중 {b}에서 얻은 자리예요. |
| 자리 하나 | 자리는 한 곳에 남았어요. 사진 {a} 중 {b}에서 얻은 자리예요. |
| 자리 `none` | 다닌 자리는 남지 않았어요. |
| 자리 `unknown`, 사진 `known` 아님 | 다닌 자리는 몰라요. 사진을 보지 못해 좌표를 물을 수 없어요. |
| 자리 `unknown`, 사진 `known` | 다닌 자리는 몰라요. 사진의 좌표를 읽지 못했어요. *(새 문장, 원본에 없음)* |
| 다녀온 곳 | 다녀온 곳은 {이름} 근처였어요. |
| `S_PLACES` | 이 자리들은 사진이 찍힌 지점이지 하루의 궤적은 아니에요. |
| `S_VISION_PARTIAL` | 사진이 더 있었지만 그중 몇 장만 보았어요. |
| `S_TRUNCATED` | 이것이 그날 사진의 전부는 아니에요. 더 있을 수 있어요. |
| `S_DAY_OPEN` | 오늘은 아직 다 가지 않았어요. 이 뒤에 무슨 일이 더 있을지는 몰라요. |

- **TN2a**: 한국어 경로의 프롬프트에 신호의 `reason` 문자열이 들어가지 않는다(가짜 까닭으로 단언). 갈래는 `kind`로만 정한다.
- **TN2b**: 사진 `none`과 `unknown`, 자리 `none`과 `unknown`은 다른 문장이다(원칙 V).
- 줄 순서·갈래 조건(하루가 안 끝남이 첫 줄, 본 장면 없는 날은 머리줄·캡션·일부만 보았음 없음)은 063 그대로.

## TN3 — 첫 문장 틀

- `FIRST_SENTENCE_FRAMES`는 원본 「첫 문장 틀」 코드 블록의 11줄과 순서·글자가 같다(테스트가 원본 블록 사본과 비교한다).
- `frameFor(day)` = `FIRST_SENTENCE_FRAMES[floor(Date.UTC(y, m-1, d) / 86400000) % 11]`.
- **TN3a** 결정성: 같은 `day`는 `TZ`와 무관하게 같은 틀. **TN3b** 연속한 11일은 11개 틀을 하나씩 낸다.

## TN4 — 꼬리

- 본 장면 있는 날: `이 기록으로 그 하루의 일기를 써라. 첫 문장은 '${frameFor(day)}'처럼 시작하고, 끝까지 '요'로 끝나는 말투로 쓴다.`
- 본 장면 없는 날(셋): 원본 「사진이 없는 날」(`zero`)·「사진은 있는데 읽지 못한 날」(`unread`)·「사진을 볼 길이 막힌 날」(`unseen`)과 글자 단위로 같다.

## TN5 — 지시문 줄

- 지금 담는 줄(머리 2~5행, 그 날 실린 한계 문장, 제목 질문, 언어 줄, 본 장면 없는 날의 꼬리)은 `~요` 판을 따라간다.
- **본 장면 있는 날에도 꼬리(TN4)를 담는다.**
- **TN5a** (P-7 유지): 제목 질문을 뺀 모든 줄이 `buildPrompt()` 결과에 들어 있다.
- **TN5b**: 틀대로 시작한 본문(예: 「오늘 내 눈에는 단풍길이 담겼어요. …」)은 되뱉기로 거부되지 않는다. 꼬리를 옮겨 적은 본문은 거부된다 — 잡히는 것은
  꼬리 줄 전체와 「이 기록으로 그 하루의 일기를 써라」 절이다. 「끝까지 '요'로 끝나는 말투로 쓴다」는 따옴표를 걷으면 16자 미만 조각이라 절로는 잡히지 않는다
  (`echoPieces()`의 기존 규칙 그대로 — 판정을 넓히지 않는다, 원칙 IV).
