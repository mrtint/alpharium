# Phase 1 — 데이터 모델: US1 코어 루프

**대상**: 001 User Story 1
**전제**: [research.md](research.md)의 결정 1~4

001 「Key Entities」가 정한 넷을 US1이 요구하는 만큼 구체화한다. **각 축 스펙이 이미
정한 것을 그대로 옮기며, 스펙에 없는 값을 새로 만들지 않는다.**

---

## 엔티티 1 — 퍼소나 (Persona)

**출처**: 001 FR-001~FR-007, 002 FR-140~FR-142

| 필드 | 성질 | 근거 |
| --- | --- | --- |
| 이름 | 1~20자, 사용자 변경 가능 | 002 (이름 변경 범위) |
| 성격 식별자 | 카탈로그 항목의 **식별자**, 불변 | 005 (표시명이 아니라 식별자로 저장) |

**저장되지 않는 것**: 기기 식별자(001 FR-005, 005 FR-404), 관측 환경(001 FR-006),
이름 변경 이력(002 FR-142), 누적 경험.

**성격의 표시명·서술은 저장하지 않고 카탈로그에서 해소한다.** 005가 식별자 저장을
택한 이유는 카탈로그 갱신이 이미 쓰인 일기의 성격을 바꾸지 못하게 하기 위함이다.

**추론 축으로 넘길 때만** 표시명·서술을 함께 실어 보낸다(002 FR-141) — 004가 카탈로그를
따로 조회하지 않아도 되도록.

**불변 조건**
- 동시에 하나만 존재한다 (001 FR-007)
- 성격은 부여 후 변하지 않는다 — 사용자도, 앱도, 시간도 (001 FR-004a)

## 엔티티 2 — 일별 집계 (Daily Digest)

**출처**: 003 FR-244의 항목 목록. **이 목록이 전부이며 항목을 추가하지 않는다**(FR-244).

| 항목 | 미관측 가능 | 비고 |
| --- | --- | --- |
| 날짜 | ✗ 항상 존재 | 집계가 귀속되는 로컬 날짜 |
| 관측 시점 | ✗ 항상 존재 | 이 집계가 만들어진 시각 |
| 걸음 수 | ✓ | 0시부터 관측 시점까지 누적 (FR-247) |
| 활동 시간대 | ✓ | 시간대 목록. 분 단위 로그 금지 (FR-248) |
| 머문 장소 | ✓ | 장소 표현 + 시간대의 쌍. 좌표·경로 금지 (FR-249) |
| 이동 여부 | ✓ | 참·거짓. 거리·속도 금지 (FR-251) |
| 사진 목록 | ✓ | 각 항목은 시각대·장소·캡션 **셋뿐** (FR-252) |
| 사진 총 개수 | ✓ (파생) | 사진 목록이 미관측이면 함께 미관측 (FR-246a) |
| 일정 목록 | ✓ | 각 일정은 제목·시간대**만** (FR-253) |
| 집계 규모 판정 | ✗ 항상 존재 | 비어 있음 / 적음 / 보통 |

### 관측 여부의 표현 — 이 모델의 핵심

003 FR-242·001 FR-010에 따라 **관측 여부는 소스가 아니라 항목 단위로** 기록한다.
「걸음 수 0」과 「걸음 수 미관측」은 휴대폰에게 다른 사실이다.

사진 항목 **안에서도** 시각대·장소·캡션 각각이 개별적으로 미관측일 수 있다(FR-252).
캡션 생성에 실패하면 지어내지 않고 미관측으로 남긴다(003 FR-235).

**따라서 모든 미관측 가능 항목은 「값이 없음」이 아니라 「관측되지 않았음」을 표현할 수
있는 형태여야 한다.** 값 자리를 비워 두는 것으로 대신할 수 없다 — 비어 있음과 미관측이
구별되지 않으면 001 FR-010이 깨진다.

### 규모 판정

**세는 대상은 여섯**: 걸음 수·활동 시간대·머문 장소·이동 여부·사진 목록·일정 목록
(003 FR-272). 항상 존재하는 셋과 파생 항목(사진 총 개수)은 세지 않는다.

| 판정 | 조건 | 근거 |
| --- | --- | --- |
| 비어 있음 | 세어진 개수 = 0 | FR-273 |
| 적음 | 0 < 개수 < 임계값 | FR-274 |
| 보통 | 개수 ≥ 임계값 | FR-274 |

**임계값은 2 이상 6 이하이며 구체적 수치는 이 모델에서 정하지 않는다**(FR-274) —
실측으로 채울 매개변수다.

판정은 **개수만으로** 결정된다. 내용·값의 크기·서술의 풍부함은 관여하지 않는다
(FR-271). 같은 입력에 항상 같은 결과(FR-275).

## 엔티티 3 — 일기 (Diary Entry)

**출처**: 004 FR-300. **셋이 전부이며 이 목록 밖의 항목을 포함하지 않는다.**

| 필드 | 성질 |
| --- | --- |
| 날짜 | 생성을 **요청한 시점**의 로컬 날짜로 고정 (001 FR-039) |
| 퍼소나 귀속 | 어느 퍼소나가 썼는지 (001 FR-018) |
| 본문 | 하나의 텍스트 덩어리. 비어 있지 않음 (004 FR-301·FR-302) |

**두지 않는 것**: 제목·태그·기분 (004 FR-301). 재료 요약 (004 FR-304 — 저장하지 않고
파생한다).

---

## 파생값 — 재료 요약 (Material Summary)

**저장 대상이 아니다.** 004 FR-304·005 FR-473에 따라 **표시 시점에 짝이 되는 집계에서
계산**한다.

- 시스템이 계산한다 — 모델의 출력에서 수량을 읽지 않는다 (004 FR-303)
- **관측된 항목만 센다** — 미관측을 0으로 표시하지 않는다 (004 FR-305, 006 FR-512)
- 셀 대상이 하나도 없으면 0을 나열하지 않는다 (006 FR-513)

**세는 항목의 최종 목록은 정하지 않는다** — 006 FR-516이 성질만 정하고 선택을 구현에
넘겼다.

## 엔티티 4 — 회상 슬롯 (Recall Slot)

추론 입력에 **자리는 존재하되 US1에서 항상 비어 있다** (001 FR-015, SC-006).

비어 있지 않은 상태는 계약 위반이다(001 Edge Cases). 즉 이 슬롯은 값을 넣을 수 있는
형태로 두되, US1의 모든 추론 요청에서 비어 있음이 **검사 가능**해야 한다.

## 엔티티 관계 — 기록 묶음 (Record Bundle)

**출처**: 005 FR-410. 이 계획에서 가장 중요한 구조적 결정이다.

```
퍼소나 1 ──< 일기 다수
             │
             └── 1:1 ── 일별 집계     ← 이 짝이 조작 단위
```

005 FR-410이 조작 단위를 **일기 하나나 집계 하나가 아니라 「기록 묶음(일기+집계)」**으로
두었다. 짝의 유지를 경로마다 방어하는 대신 **구조로 보장**한다.

**이것이 의미하는 것**

- 저장은 전부 성공하거나 전부 실패한다 (005 FR-411). 일기만 있고 근거가 없는 상태,
  또는 그 반대를 만들지 않는다 (001 FR-032)
- 재생성 시 이전 일기와 이전 집계가 **함께 대체**된다 (001 FR-040b)
- 소프트 삭제·복구에서도 함께 움직인다 (001 FR-034b) — US1 범위 밖이지만 **구조는
  지금 정해야 나중에 고칠 수 있다**

**원본 로그를 담을 자리가 존재하지 않는다** (005 FR-402). 저장 시점에 걸러내는 것으로
대신하지 않는다 — 담을 자리 자체를 두지 않는 것이 구조적 보장이다.

### 이 흐름에서 절대 일어나면 안 되는 것

| 금지 | 근거 |
| --- | --- |
| 빈 집계로 추론을 돌린다 | 001 FR-013, 원칙 0의 「근거의 한계」 |
| 「적음」을 이유로 거부·지연한다 | 001 FR-043a, 006 FR-546 |
| 추론 축이 입력이 쓸 만한지 재판정한다 | 001 FR-013b, 003 FR-282 |
| 실패를 준비된 문장으로 메운다 | 001 FR-024, 004 FR-353, 헌법 원칙 II |
| 누락 항목을 기본값으로 채워 저장한다 | 001 FR-025 |
| 취소된 추론의 부분 결과를 남긴다 | 001 FR-027 |
| 화자를 고쳐 저장한다 | 004 FR-349 |
| 일기만 저장하고 집계를 저장하지 않는다 | 001 FR-032, 005 FR-411 |
| 재생성 시 이전 집계를 재사용한다 | 001 FR-040a, 003 FR-263 |
| 미관측을 0이나 값-없음으로 표시한다 | 001 FR-010, 006 FR-514 |
| 원본 로그를 남긴다 | 001 FR-029, 003 FR-255, 005 FR-402 |
| 일기 본문·원시 신호를 로그에 남긴다 | 001 FR-037, 005 FR-405 |
