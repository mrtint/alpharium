# Quickstart: 128 전후 비교

전제: 표본 `scripts/samples/documents/`(로컬 전용, 저장소에 없음). 기록에는 장수·기기·종류만.

1. 안드로이드(SM-S901N, Metro 번들): 표본에 템플릿 EXIF를 옮겨 붙이고 오늘 날짜로 `PocketlogSeed`에 심는다(README 「documents/」). 오늘 일기를 지우고 쓴다.
2. 볼 것: 일기 본문에 지어낸 금액·날짜가 없다 · 캐러셀 0장 · 고정 줄 취지의 문장 · 화면 캡처 장의 묘사 시간 0(로그). 보통 사진 날(11-22 표본) 하나를 다시 써 빠진 사진 0장 확인.
3. iPhone 14(개발 서명 Release, devicectl): `npm run ios:seed`로 같은 묶음을 심고 같은 확인 + 앱 밖 장당 시간.
4. 결과를 아래 「기록」에 적는다.

### 적용 후 (2026-11-24, SM-S901N, dev 빌드 + Metro 번들, 같은 사진)
- 11-24(카메라 영수증 6·앱 화면 2, 실제 사진): 영수증 6장 모두 문서로 걸림(문답 꼴 5 + 「The image shows a document…」 낱말 1 — 낱말 목록이 문답 꼴을 피한 묘사를 잡았다). `Screenshot_…`은 파일 이름으로, `file_…`(590×1280)은 비율로 묘사 없이 건너뜀. 본문 「글자가 적힌 사진 여덟 장… 읽지 못했어요」 취지, **지어낸 금액·날짜 0건**(적용 전 2건 이상), 일기 사진 0장. 사진 단계 27.2초 → 24.4초(묘사를 건너뛴 장 2).
- 11-22(보통 4): **오탐 0** — 「a bed, a table…」 포함 4장 모두 남음, 일기 사진 4장.
- 놓친 사례: 이 표본에서는 0(영수증 12건 중). 표본이 작다.
- 시딩 함정: 시딩 템플릿 EXIF의 회전값 6을 그대로 옮기면 미디어 저장소가 크기를 90° 돌려 보고해(`orientation=90`) 세로 화면 캡처가 가로로 보인다 — 비율 판정을 볼 때는 회전값을 1로 고친다(실제 스크린샷은 회전값이 없다).
- 「바꾸지 않는다」(FR-011·012·013): 브랜치 diff에 `src/vision/select.ts`·`src/app/material.ts`·`src/schedule/auto-write.ts`·`package.json`·`package-lock.json` 변경 0.

### 적용 후 (2026-11-24, iPhone 14, 개발 서명 Release, 같은 사진 8장 + 그날 있던 표본 사진 4장)
- 12장 중 선별 8장. 남은 묘사 4장은 모두 풍경(표본 사진), 문서류 4장은 걸러짐. 본문에 영수증발 금액·날짜 0건, 일기 사진 4장(풍경) — 섞인 날(FR-007) 확인. 사진 단계 11.9초(앱 안에 머묾 — 앱 밖 장당 시간은 못 쟀다).
- iOS `exeForMetadata()`도 filename·width·height를 준다. 다만 파일 이름이 `IMG_0500.JPG`처럼 원래 이름이 아니라 **iOS에서는 이름 판정이 아니라 비율 판정**(1440×3120·590×1280)으로 화면 캡처가 잡힌다(예상대로).
- **못 본 것**: iPhone 적용 전 빌드로 같은 사진의 일기(전후 비교의 「전」) · Release에서 JS 로그가 콘솔에 오지 않아 장별 판정(문서/건너뜀)은 결과로만 확인 · 앱 밖 장당 시간.

## 남은 위험 (코드 리뷰 Minor에서 옮김)
- 문서 낱말을 묘사 전체에서 찾으므로 보통 사진의 묘사에 곁가지로 나와도 빠진다(예: 「a man reading a document at a café」). 지어내기를 막는 방향의 오탐이다 — 실측 오탐은 0/4.
- 안드로이드 미디어 저장소의 가로·세로가 EXIF 회전에 따라 돌아 보고될 수 있다(시딩에서 실측). 카메라 4:3·16:9는 어느 방향이든 2 미만이라 영향 없고, 세로 파노라마가 화면 캡처로 잡힐 수 있다 [미확인].
- 이름 접두는 `screenshot`뿐이다 — 「스크린샷」·`Screen Shot` 같은 이름은 비율 판정에만 기댄다.
- 영수증뿐인 날은 「사진은 N장이 남았어요」와 「글자가 적힌 사진이 N장…」이 같은 장을 두 번 말한다 — 실기기 본문(S22 두 회차)에서는 어색하지 않았다.
