# Quickstart: 128 전후 비교

전제: 표본 `scripts/samples/documents/`(로컬 전용, 저장소에 없음). 기록에는 장수·기기·종류만.

1. 안드로이드(SM-S901N, Metro 번들): 표본에 템플릿 EXIF를 옮겨 붙이고 오늘 날짜로 `PocketlogSeed`에 심는다(README 「documents/」). 오늘 일기를 지우고 쓴다.
2. 볼 것: 일기 본문에 지어낸 금액·날짜가 없다 · 캐러셀 0장 · 고정 줄 취지의 문장 · 화면 캡처 장의 묘사 시간 0(로그). 보통 사진 날(11-22 표본) 하나를 다시 써 빠진 사진 0장 확인.
3. iPhone 14(개발 서명 Release, devicectl): `npm run ios:seed`로 같은 묶음을 심고 같은 확인 + 앱 밖 장당 시간.
4. 결과를 아래 「기록」에 적는다.
