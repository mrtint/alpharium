# Data Model: 이 휴대폰 (058)

새로 저장하는 값은 없다. 지우는 것과 화면에 넘기는 값만 정의한다.

## §1 지우는 것 / 남기는 것 (기기 `files/` 아래)

| 자리 | 무엇 | 지우기 |
| --- | --- | --- |
| `diary/YYYY-MM-DD.json` | 일기(읽을 수 없는 것 포함) | **지운다** |
| `diary/YYYY-MM-DD.json.writing` | 쓰다 남은 임시 파일 | **지운다** |
| `diary/`의 그 밖 이름 | (지금은 없다) | 남긴다 |
| `vision-cache/*` | 사진 리사이즈 사본(017) | **지운다**(디렉터리는 남긴다) |
| `preferences/notified.json` | 날짜별 `{ notificationId, acknowledged }` | **`{}`로 비운다** + 각 id의 알림을 트레이에서 거둔다 |
| `preferences/auto-write-skipped.json` | 057 건너뛴 날 | 남긴다(FR-012a) |
| `preferences/auto-diary.json` | 자동 쓰기 설정 | 남긴다 |
| `preferences/geocoding-setting.json` | 장소 이름 | 남긴다 |
| `preferences/onboarding.json` | 첫 실행 기록 | 남긴다 |
| 캐릭터 이름·선택 파일(035·007) | 이름·선택 | 남긴다 |
| 모델 디렉터리(`<key>.bin`·구간 파일·메타데이터) | 받은 모듈 | 남긴다 |
| 쓰기 잠금 파일 | 020 잠금 | 지우기 동안 쥐었다 놓는다(R2) |

## §2 지우기 결과 `WipeOutcome` (`src/app/wipe-diaries.ts`)

```text
{ kind: "wiped" }                 모두 지웠다
{ kind: "busy" }                  잠금을 얻지 못했다 — 아무것도 건드리지 않았다
{ kind: "failed"; reason: string } 잠금은 얻었고 일부 단계가 던졌다 — 나머지는 시도했다
```

시각·편수·걸린 시간을 담지 않는다(FR-017).

## §4 홈 ↔ AppFrame 지우기 요청

| 값 | 주인 | 설명 |
| --- | --- | --- |
| `wipeRequest: number` | `AppFrame` state | 0이면 요청 없음. 확정마다 1 오른다 |
| `onWipeReady(token)` | `AppFrame` 콜백 | 홈(또는 홈을 못 그리는 `DiarySection`)이 멈춤을 마쳤다. 같은 토큰에 한 번 |
| `diaryKey` | `AppFrame` state | 지운 뒤 1 올려 `DiarySection`을 다시 마운트(040 `autoGeneratedToken`과 합친 key) |
| `requestWipe(): Promise<WipeOutcome>` | `AppFrame` 콜백 → `SettingsSection` | 토큰을 올리고 `onWipeReady`를 기다린 뒤 `wipeDiaries`를 돌려 결과를 준다. `wiped`·`failed`면 설정을 닫고 오늘로 두고 `diaryKey`를 올린 뒤 resolve |
| `wiping: boolean` | `SettingsSection` 로컬 | 확정 ~ 결과 사이 참. 행 비활성 |
| `wipeBlocked: boolean` | `SettingsSection` 로컬 | 마지막 시도가 `busy`. 겹이 닫히면(언마운트) 함께 사라진다 |

## §5 설정 화면 값 (`SettingsScreen` props 추가)

| prop | 형 | 출처 |
| --- | --- | --- |
| `moduleSizeText` | `string \| null` | `formatModuleBytes(readModuleBytes(...))`, 실패·읽기 전 `null` → 값 비움 |
| `wipeEnabled` | `boolean` | 편수 > 0 && 편수를 읽음 && `!wiping` |
| `onOpenWipe` | `() => void` | 조립부가 편수를 다시 세어 0보다 크면 대화상자를 연다 |
| `wipeBlockedText` | `string \| undefined` | R10 문구, `wipeBlocked`일 때만 |

## §6 확인 대화상자 `WipeConfirmDialog` props

`count: number`(여는 순간 센 편수, ≥1), `onCancel`, `onConfirm`. 제목은 `wipeTitle(count)` = 「일기 {count}편을 모두 지울까요?」.
