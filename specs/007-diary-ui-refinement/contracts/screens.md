## 2. 그만두기 전이

```
writing --「그만두기」--> (stop() 호출) --> list
```

### 규칙

1. **`stop()`을 부른다** — 없으면(데스크톱) 부르지 않고 넘어간다
2. **그 생성의 결과를 기다리지 않고 목록으로 간다**
3. **돌아온 결과를 화면 상태에 담지 않는다**(FR-014a)
4. 목록을 다시 읽는다 — 그만둔 하루는 저장되지 않았으므로 없다(FR-014)

### ⚠️ 3번이 왜 필요한가

`stopCompletion()`은 **거기까지 생성된 글이 담긴 결과로 정상 resolve된다**(2026-08-17
실측). 「끊었으니 글이 없다」가 성립하지 않는다.

**이중 방어다**:

- **파이프라인 계층**: `acceptance.ts`가 `unfinished`를 가장 먼저 보므로
  `rejected: unfinished`가 되고 `PipelineResult`에 `entry`가 실리지 않는다(002 FR-012)
- **화면 계층**: 그만두면 `afterGeneration()`을 부르지 않고 곧장 목록으로 간다

### 새 갈래를 만들지 않는다

`{ kind: "cancelled" }`를 **두지 않는다.** 두면 「거기까지 쓴 글을 담을까」라는 물음이
생기고 그 자리가 FR-014a를 뚫는 통로가 된다.

### 검증 표

| # | 상황 | 기대 | 기기 | FR |
| --- | --- | --- | --- | --- |
| 1 | 생성 중 그만두기 | `stop()`이 불린다 | 불필요 | FR-013 |
| 2 | 생성 중 그만두기 | 목록으로 간다 | 불필요 | FR-015 |
| 3 | 부분 결과가 돌아온다 | **어느 화면에도 보이지 않는다** | 불필요 | FR-014a, SC-006a |
| 4 | 그만둔 뒤 목록 | 그 하루가 **없다** | 불필요 | FR-014, SC-006 |
| 5 | `stop`이 없다(데스크톱) | 그래도 목록으로 간다 — 죽지 않는다 | 불필요 | — |
| 6 | `stop()`이 예외를 던진다 | 그래도 목록으로 간다 | 불필요 | — |
| 7 | 실기기에서 그만두기 | **10초 안에** 목록 | **필요** | SC-005 |
| 8 | 그만둔 직후 다시 쓰기 | 「이미 쓰고 있다」로 막힐 수 있다 | 불필요 | Edge Case |

| `list` | 앱을 닫는다 | 006 그대로 |

## 4. 쓰기 자리 (`WritePrompt`) — 목록 화면 안

**clarify Q5**: 캐릭터·날짜·덮어쓰기 예고가 **「일기 쓰기」 자리에 모인다**(FR-002a).
확인 화면을 새로 두지 않는다(FR-002b).

### 그리는 것

| 요소 | 내용 | FR |
| --- | --- | --- |
| 고른 캐릭터 | 누가 쓰는가 + 바꾸는 길 | FR-002 |
| 옮겨졌다는 알림 | `movedFrom`이 있을 때만 | FR-005a |
| 쓰게 될 하루 | 「어제(2026-08-19)를 쓴다」 꼴 | FR-023 |
| 덮어쓰기 예고 | 이미 있을 때만 | FR-024 |
| 「일기 쓰기」 | 언제나 같은 자리 | 006 S1 |

### ★ `onWrite`는 여전히 `WritePrompt`를 보지 않는다

```
onWrite: () => void        // 인자 없음 — 006 그대로
toWriting(): AppScreen     // 인자 없음 — 006 그대로
```

**「이미 있는가」를 아는 것은 화면이고, 쓰기를 시작하는 함수는 여전히 모른다.**
안다는 것과 그것으로 갈리는 것은 다르며 후자만이 원칙 I 위반이다(FR-025).

### 검증 표

| # | 상황 | 기대 | 기기 | FR |
| --- | --- | --- | --- | --- |
| 1 | 목록 화면 | 쓰게 될 하루가 보인다 | 불필요 | FR-023, SC-009 |
| 2 | 그 하루가 이미 있다 | 덮어쓰기 예고가 **누르기 전에** 보인다 | 불필요 | FR-024, SC-010 |
| 3 | 그 하루가 이미 있다 | 눌렀을 때 **실제 생성이 돈다** | 불필요 | FR-025, SC-014 |
| 4 | `toWriting()` 서명 | **인자가 없다** | 불필요 | FR-025 |
| 5 | 캐릭터가 옮겨졌다 | 알림이 보인다 | 불필요 | FR-005a, SC-003a |
| 6 | 03:59와 04:01 | **서로 다른 하루**를 가리킨다 | 불필요 | Edge Case |
| 7 | 새 화면 수 | **0개 늘었다** | 불필요 | FR-002b, FR-028 |
