# Quickstart: 쓴 날 사진 확대 화면 (067) — 실기기 검증

기기 없는 테스트는 배선과 판정만 본다. 손맛·창·뒤로 가기는 여기서 본다(원칙 V). dev(debug) 빌드만 — release는 만들지 않는다(AGENTS).

## 준비

1. `adb devices`에서 기기가 `device`, 잠금 해제(`dumpsys trust`의 `deviceLocked=0`).
2. 새 네이티브 의존성이 없으므로 이미 설치된 dev APK를 그대로 쓴다. Metro: `EXPO_PUBLIC_APP_ENV=dev npx expo start --dev-client` — **`CI=1`을 붙이지 않는다**(파일 감시가 꺼져 변경이 반영되지 않는다, 067 실측). `adb reverse tcp:8081 tcp:8081`.
3. 사진 2장 이상인 쓴 날이 있어야 한다 — 없으면 `npm run seed:day -- rich <사흘 안의 날>` 뒤 그 날을 쓴다. 1장인 날도 하나(첫 실행 자동 일기 등).
4. 움직임은 `MSYS_NO_PATHCONV=1 adb shell screenrecord /sdcard/zoom.mp4`로 녹화하고 프레임을 뽑아 본다. 손가락 위치가 필요하면 `settings put system show_touches 1`(끝나면 0).

### 실기기에서 드러난 결함 — 고침

- **사진이 한 장인 날, 사진 위에서 가로로 쓸고 떼면 확대 화면이 열렸다**(5회 중 재현). 캐러셀이 있으면 그 팬이 누름을 빼앗지만 한 장이면
  팬이 없어 `Pressable`이 손가락을 그대로 누름으로 친다. 누른 자리와 뗀 자리가 10 안일 때만 누름으로 친다(`isTap`·`TAP_SLOP 10`, ZV12·ZC8) —
  고친 뒤 같은 동작 5회 중 0회, 제자리 누름은 열림.

### 관찰 — 이 기능 밖 (뒤에 원인 확인·수정: `File.text()` 공유 객체 해제 → `textSync()`, AGENTS 「안드로이드·Expo·기기」)

- **앱을 강제 종료 후 다시 열면 멀쩡한 일기가 가끔 「이 날의 일기 파일이 손상됐어요」로 보인다**(이 세션 콜드 스타트 약 열 번 중 다섯 번 안팎, 10월 8일·9일 모두,
  파일 내용은 정상이고 다시 열면 정상). 목록 판정(`listDiaries`)이 `load()`의 예외를 「읽을 수 없음」으로 삼키는 자리다. 066이 `load()`에 더한
  `fs.documentDirectory?.()`(`await import("expo-file-system")`)가 의심되나 재지 않았다. 067 변경(사진 확대)과 무관하게 이 브랜치를 만들기 전 Metro `CI=1` 실험 때도 보였다.
- 확대 화면 아래 내비게이션 바 자리가 옅은 회색 띠로 남는다(`navigationBarTranslucent`가 이 기기에서 그 자리까지 덮지 않음 — 짐작).

### Convergence 태스크 (T024~T026)

- **T026 통과** — 글꼴 2.0배로 본문을 길게 해 스트립을 접은 뒤 보이는 사진 끝을 눌러 확대 화면을 열고 뒤로 가기로 닫았다. 연 직전·닫은 직후 스크린샷이
  상태 표시줄을 뺀 전 영역에서 픽셀 단위로 같다(`ImageChops.difference(...).getbbox()` → `None`) — 접힘·스크롤 위치 그대로(FR-013).
- **T024 고치지 못함(원인만 확인)** — 확대 화면의 창이 내비게이션 바 위에서 끝난다: `uiautomator dump`의 `photo-viewer` 경계가 `[0,0][1080,2285]`(화면 2400).
  RN 0.86 `ReactModalHostView`는 `navigationBarTranslucent`면 대화상자 창에 `enableEdgeToEdge()`를 부르지만 이 기기(Android 13)에서는 창이 그 자리까지 내려오지 않고,
  투명 `Modal`이라 그 띠에 뒤의 홈(밝은 면)이 비친다. 고치려면 대화상자 창 플래그를 만지는 네이티브 코드가 필요해 이 기능의 제약(새 의존성·네이티브 0, FR-016) 밖이다 —
  저장소 소유자 판단으로 남긴다.
- **T025 미확인** — 핀치는 사람 손이 필요하다(위 Q8).
