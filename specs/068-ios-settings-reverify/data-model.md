# Data Model: iOS 설정·개발자·진단 화면 재검증과 고장 수정

저장되는 데이터가 새로 생기지 않는다(파일·`preferences/` 변경 0). 다음 두 값만 코드 안에 있다.

## 플랫폼

- 값: `"android" | "ios"` — `App.tsx`가 `Platform.OS === "ios" ? "ios" : "android"`로 이미 만든다(온보딩의 `platform`과 같은 값). 새 갈래를 만들지 않는다.

## 배터리 행 안내 (`batteryRowHint`)

| 입력 `platform` | 출력 |
|---|---|
| `"android"` | 기존 `SETTINGS_TEXT.permBatteryHint` — 「배터리 사용 · 제한 없음으로 두면 제때 써요」(무변경) |
| `"ios"` | 「저전력 모드를 끄면 제때 써요」 |

- 출력은 문자열 하나이고 행 이름 「배터리」·동작(`onOpenAppSettings`)은 두 플랫폼이 같다.
- 순수 함수이며 `now`·`Platform`을 읽지 않는다(입력만으로 결정).

## 훑기 결과 목록 (문서 전용, `quickstart.md`에 기록)

| 필드 | 뜻 |
|---|---|
| 화면·행/버튼 | 예: 설정 › 권한 › 사진 |
| iOS 관측 | 정상 · 오류(로그 한 줄) · 문구 어긋남 · 동작 안 함 |
| 조치 | 수정 · 감춤(소유자 결정) · 로드맵 기록(범위 밖) · 해당 없음 |
| 확인 환경 | 시뮬레이터(iOS 26.5) / 실제 iPhone 미확인 |

코드·저장소에 이 표를 읽는 것은 없다(원칙 IV — 채점 코드가 아니다).
