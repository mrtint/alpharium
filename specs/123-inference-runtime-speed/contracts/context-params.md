# Contract: 모델을 여는 값 (123)

`contextParams(modelPath, threads?, resident?, extras?)` — 종전 호출은 결과가 바뀌지 않는다.

- CP1: 채택 옵션이 없으면 출력은 123 이전과 같다(키가 늘지 않는다).
- CP2: `flash_attn_type`은 채택된 값만 싣는다.
- CP3: `cache_type_k`/`cache_type_v`는 기기 메모리가 읽혔고 2 GiB 미만일 때만 `"q8_0"`을 싣는다. 읽지 못했거나 이상이면 키가 없다. 기준값은 상수 한 곳(사람이 정한 값 주석).
- CP4: 두 값을 읽는 자리는 이 함수와 메모리 판정 함수뿐이다.

# Contract: 제목 호출의 상태 재사용 (채택 시)

- TR1: 이어받기 실패는 제목을 새로 묻는 경로로 폴백한다. 일기를 버리지 않는다.
- TR2: 저장·복원 호출은 `tracked()`를 거쳐 `unload()`가 기다린다(079).
- TR3: 상태 파일은 `unload()`·실패·그만두기 어느 경로에서도 남지 않는다.
- TR4: 제목 구간의 박동은 종전처럼 나온다(092).
