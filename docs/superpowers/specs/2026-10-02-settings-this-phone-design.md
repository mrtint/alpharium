## 목적

## 보드에서 옮길 것

- 묶음 머리 「이 휴대폰」 — 「권한」 묶음 다음, 「정보」 묶음 앞(보드 `6c` 순서).
- 행 「쓰는 모듈」 — 값은 받은 모듈 합계(보드 `1.2GB`, 15·`neutral-600`·고정폭 숫자). 누를 수 없고 ›가 없다.
  `1.2GB`가 온보딩 진행 문구의 전체 크기와 같다 — 필수 에셋 셋(`ESSENTIAL_ASSET_KEYS` = `v1`·`v2`·`a1`)의 합이다.
- 행 「일기 모두 지우기」 — 라벨 15/600이 `accent-700`(= `COLORS.danger`), 값·› 없음.
- 확인은 보드 `2d`와 같은 틀(RNR AlertDialog = 050 `ConfirmDialog`): 제목 「일기 {n}편을 모두 지울까요?」, 본문
  「되돌릴 수 없어요. 이름과 설정은 남아요.」(문구표 기준 — 메모 원문과 다르면 표가 원문), 「지우기」(빨강)·「취소」. 덮개를
  눌러도 닫히지 않고 뒤로 가기는 「취소」다.
- 지운 뒤 홈으로 돌아가 오늘(안 쓴 날)을 보인다. 쓰는 중이면 먼저 쓰기를 멈춘다.

## 접근 — 홈에 멈춤 요청을 내려보내고, 멈춘 뒤 지운다 (채택)

**사실**: 쓰는 중 상태는 `DiaryHomeScreen`에, 파이프라인의 `stop()`은 `DiarySection`에 있다. 설정 겹(`AppFrame`)은 둘에 직접
닿지 않는다. 홈을 다시 마운트하는 것만으로는 생성이 멈추지 않는다 — 그대로 두면 생성이 뒤에서 끝나 **지운 뒤에 저장된다.**

흐름:
1. 설정의 「일기 모두 지우기」 → 조립부가 편수 n을 **그 순간** `listDays()`로 세어 확인 대화상자를 연다(미리 세어 둔 값을 쓰지 않는다).
2. 「지우기」 → `AppFrame`이 홈에 지우기 요청 신호(토큰)를 내려보낸다.
3. 홈은 쓰는 중이면 054의 그만두기 경로(`cancel` — `cancelled` 표식 + `stop()`)로 멈추고, **도는 생성 `Promise`가 끝날 때까지
   기다린 뒤** 「멈췄다」를 알린다. 쓰는 중이 아니면 곧바로 알린다.
4. `AppFrame`이 지우기(`src/app/wipe-diaries.ts`)를 실행하고, 설정을 닫고, 고른 날을 오늘로 두고, 홈을 다시 마운트해 목록을 새로 읽힌다.

버린 접근: 파이프라인·쓰기 제어를 `AppFrame`으로 끌어올리기(054·057 계약을 다시 짜야 해 범위를 넘는다), 멈추지 않고 지운 뒤
다시 마운트(위 사실 때문에 틀린다).
