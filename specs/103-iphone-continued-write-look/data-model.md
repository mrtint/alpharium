# Data Model: 103

저장되는 데이터가 없다. 막대 값은 박동에서 계산해 시스템 진행 표시에만 넘기고 저장하지 않는다(092).

- **박동 무게**: 사진·조각·토큰 박동 하나가 단계 안 무게 합 `w`에 더하는 값. 후보 1·4·1(사람이 정한 값).
- **반몫 무게 `k`**: 단계 몫의 절반에 닿는 `w`. 후보 준비 1(박동 없음)·사진 2·글 1000(사람이 정한 값).
- **위치**: `단계 시작 + 몫 × w/(w+k)` (칸). 단계가 바뀌면 `w`는 0으로 돌아가고 위치는 새 몫의 시작으로 뛴다. 보고마다 직전 값보다 한 칸 이상 오르고 `PROGRESS_TOTAL - 1`을 넘지 않는다(092).
- **실측 기록**: `quickstart.md`의 표(회차, 조건, 시작·끝 시각, report 횟수, 구간별 completedUnitCount, 종료 결과).
