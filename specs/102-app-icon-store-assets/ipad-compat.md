# 102 iPad 호환 모드 점검 (시뮬레이터)

**이것은 실기기 점검이 아니다.** 실기기 iPad는 없어 iPad 시뮬레이터로만 봤다(원칙 V). 점검 범위도 좁다 — 아래 「못 본 것」을 읽는다.

## 한 것

- 2026-10-23, `supportsTablet: false`로 prebuild한 iOS 앱(`TARGETED_DEVICE_FAMILY = 1`, `UIDeviceFamily = [1]`)을 시뮬레이터 Release(개발 환경, `EXPO_PUBLIC_APP_ENV=dev`)로 빌드해 **iPad Pro 11-inch (M5) 시뮬레이터**(iOS 27)에 설치·실행했다(`xcrun simctl install`·`launch`, 스크린샷 `simctl io screenshot`).

## 본 것

- 앱이 iPad에서 **iPhone 크기의 세로 창(호환 모드)** 으로 열린다. 화면 가운데에 iPhone 비율의 창이 뜨고 위에 창 조절 점 세 개가 붙는다.
- 첫 화면(스플래시 — 빨강 정사각 마크, 「Pocketlog」, 하단 「휴대폰 안에서만」·로딩 점)이 창 안에서 잘리거나 겹침 없이 그려진다.
- 첫 실행의 사진 권한 시스템 창이 뜬다(문구: 「그날 찍힌 사진을 읽어 하루를 일기로 씁니다. 사진은 휴대폰 밖으로 나가지 않습니다.」).
- 앱 아이콘은 iPad 홈 화면에 새 「P」로 들어간다고 기대하지만 **이번에 홈 화면을 보지 않았다.**

## 못 본 것 (점검하지 않았다)

- 권한 요청 이후의 화면 — 필수 모듈 동의, 내려받기, 작명, 홈, 설정. 시뮬레이터에는 모델이 없어 첫 실행이 모듈 동의·내려받기에서 이어지므로(약 2GB) 거기서 멈춘다. 이 이후는 확인하지 않았다.
- 창 크기를 바꿀 때(iPadOS 26 창 조절)의 반응.
- 가로 방향 — `orientation: portrait`라 앱은 세로 고정이다. 확인하지 않았다.

## 깨진 곳

찾은 것 없음(본 범위 안에서). **본 범위가 첫 화면·권한 창뿐이라 「안 깨진다」는 결론은 아니다.** 후속으로 모델이 설치된 상태에서 홈·설정·일기 화면을 한 번 보는 것이 남아 있다.

## 2026-11-28 다시 점검 — 모델을 넣고 홈·설정·일기까지 (시뮬레이터)

**이것도 실기기 점검이 아니다.** 위 2026-10-23 기록의 「못 본 것」을 이어 본 것이고, 화면은 그 사이 크게 바뀌었다.

### 한 것

- 앱: `origin/main`(`0ab23fb`, 로컬에만 있는 137 일기 모델 v2는 **없다**)을 `expo prebuild --clean` → 시뮬레이터 **Release**, `EXPO_PUBLIC_APP_ENV=dev`, 1.0.0(20), `UIDeviceFamily = [1]`.
- 기기: **iPad Pro 11-inch (M5) 시뮬레이터**, iOS 27.0, Xcode 27.2. 창 조절 점이 붙는 창 모드였다(시뮬레이터의 기본 상태 그대로, 설정은 바꾸지 않았다). 전에 깔려 있던 앱은 지우고 새로 깔았다.
- 모델: **내려받지 않았다**(소유자 결정). 일기 모듈은 맥의 terrarium `kanana-v4_3e-dpo-iq4_nl_im96.gguf`(1,241,435,520 B, md5 `0de25a2d5cf36d7e6b8ba1da968436ff`), 사진 모듈 둘은 다른 시뮬레이터의 사본(`b0f40eda…`, `7e8624e7…`)을 `Documents/models/`에 복사했다. 모두 로스터의 크기·md5와 같았고, 앱이 받기 대신 검증해 세 파일 모두 `passed`를 남겼다.
- 사진: 맥에 있던 표본 캐시(`scripts/e2e-sample/.cache`) 129장을 심었다(기준일 2026-11-28, 보관함의 기본 사진 6장은 지우지 않았다). 사진 권한은 `simctl privacy grant`로 줬다(권한 창의 버튼 탭이 먹지 않았다).
- 일기: 2026-11-16(사진 5장·장소 5곳)을 시뮬레이터에서 **실제로 썼다**. 시작부터 저장까지 2~3분 안(성능 측정이 아니다). 입력(하루)은 심은 것이다.

### 본 것 — 깨짐 없음

앱은 가운데 세로 창(약 417×1210pt)으로 열린다. 아래 화면에서 글 잘림·겹침·화면 밖 요소를 보지 못했다(창 조절 점 문제는 따로 적는다).

- 스플래시, 사진·알림 권한 창, 다운로드 동의창, 「준비됐어요」, 작명(화면 키보드를 띄우면 배치가 위로 맞춰지고 버튼이 가려지지 않음, 한글 입력), 「잠시만요」, 자동 쓰기 설정 창
- 홈: 사진 0장인 날, 5장인 날, 달력 대화상자, 쓰는 중
- 쓴 날: 제목·캐러셀·본문·「다시 쓰기」, 지도 면(첫 진입 애니메이션 중간과 끝, 점을 눌렀을 때 사진 카드), 확대 화면 열기·닫기
- 설정, 이름 바꾸기, 장소 이름 대화상자, 서체 라이선스
- 창 높이를 끌어 줄였을 때: 쓴 날이 다시 배치되고, 쓸어 올리면 「다시 쓰기」가 보였다(너비는 바뀌지 않았다)

지도 면은 지도 좌우에 좁은 빈 띠가 있다. 지도가 정해진 비율을 지키기 때문으로 읽힌다(`RouteFace.tsx`의 `boxW = min(width, height / ROUTE_ASPECT)`). iPhone에서도 같은지는 이번에 견주지 않았다.

### 깨진 곳

**B1 — 창 조절 점(빨강·노랑·초록)이 앱의 왼쪽 위를 덮는다.** 접힌 상태의 점은 창 안 좌표로 대략 x 21~62pt, y 44~65pt다(캡처에서 읽은 값).

| 화면 | 가려지는 것 | 캡처 |
| --- | --- | --- |
| 설정·이름 바꾸기·서체 라이선스 | **뒤로 가기(「‹ 일기」·「‹ 설정」)** | [settings-overlap](ipad-2026-11-28/settings-overlap.jpg), [rename-keyboard](ipad-2026-11-28/rename-keyboard.jpg) |
| 홈(안 쓴 날·쓰는 중·쓴 날) | 「2026년 11월」 | [home](ipad-2026-11-28/home.jpg), [written](ipad-2026-11-28/written.jpg), [map-face](ipad-2026-11-28/map-face.jpg) |
| 작명 | 「POCKETLOG」 | [welcome-overlap](ipad-2026-11-28/welcome-overlap.jpg) |
| 사진 확대 | 장수 표시 「1 / 4」 | [viewer-overlap](ipad-2026-11-28/viewer-overlap.jpg) |

- **뒤로 가기의 실제 동작**(설정 화면, 앱 전체 좌표): 글자 한가운데와 왼쪽(251,63)·(240,73)을 누르면 앱으로 가지 않고 **창 메뉴가 펼쳐졌다**([settings-window-menu](ipad-2026-11-28/settings-window-menu.jpg)). (245,80)·(268,80)은 직후(약 1초) 캡처에서 반응이 없었다. 점 아래 가장자리 (232,84)·(250,82)는 돌아갔다. 즉 **눌리기는 하지만 보이는 글자를 누르면 안 된다.**
- 앱의 하위 화면 겹(`StackLayer`)에는 가장자리 밀기로 돌아가는 동작이 코드에 없다(안드로이드 뒤로 가기만 가로챈다). 시뮬레이터에서 밀어 보지는 않았다.
- 원인은 **짐작**이다: 앱이 창 조절 점 자리를 안전 영역으로 받지 않는 것으로 보인다. 확인하지 않았다.

**B2 — iPad를 가로로 돌리면 앱이 옆으로 누운 채 보인다**([landscape](ipad-2026-11-28/landscape.jpg)). 시스템 상태 표시줄은 가로, 앱 창 내용은 90도 돌아가 있다. `orientation: portrait`의 결과로 보인다(짐작). 시뮬레이터 회전 한 번·화면 하나(쓴 날)만 봤고, 실제 iPad가 같은지는 모른다.

고치지 않았다. 후속 과제 제안: 「iPad 창 모드에서 창 조절 점이 뒤로 가기를 가리지 않게 한다」(B1, 확인에 B2 판단 포함).

### 못 본 것

- **실기기 iPad 전부.**
- iPadOS의 「전체 화면 앱」 멀티태스킹 설정 — 그 설정에서도 점이 겹치는지 모른다(심각도 판단에 필요하다).
- 다른 iPad 크기(mini·13형), 큰 글자·VoiceOver, 하드웨어 키보드, Stage Manager의 여러 창
- 다운로드 진행 슬라이드(파일이 이미 있어 나오지 않았다), 모바일 데이터 동의, 실패 토스트, 제약 띠, 첫 일기 확인창, 쓰는 시각 대화상자, 일기 모두 지우기 창, 오픈소스 라이선스, 개발자·진단 화면, 설정에서 밖으로 나가는 링크
- 알림 표시·누름, 앱을 나간 채 이어 쓰기, 자동 쓰기
- 화면 글이 iPad에서도 「휴대폰」이라고 부른다(「이 휴대폰」 등) — 본 사실만 적고 판단하지 않았다.
