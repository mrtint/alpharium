# 설계: 홈 날 스트립을 오늘에서 끝나는 이어 스크롤로 (보드 밖)

로드맵 진행 예정 과제 「주간 스트립을 오늘에서 끝나는 이어 스크롤」. 049 계약 S4·S6·SW1·SW3~SW5를 뒤집는다.

## 목적

- 지금 스트립(`src/ui/DayPicker.tsx`, 049)은 일~토 7칸이고 좌우로 넘기면 7칸이 통째로 이전·다음 주로 바뀐다.
- 사용자 제안(2026-11-14)과 소유자 확인(2026-11-16, iPhone 14에서 114 빌드를 써 본 뒤 「주 단위로 탁 넘어가는 현상이 그대로」): 하루 단위로 이어 흐르는 스트립이 맞다. 소유자가 다른 앱 화면 녹화를 참조로 보여 줬다.
- 참조 녹화에서 본 것(0.4초 간격 프레임): 칸이 하루씩 이어 흐르고 월 경계(11/30→12/1)를 표시 없이 지나간다. 스크롤만으로 고른 날(검은 원)은 바뀌지 않는다. 멈춘 프레임은 모두 칸 경계에 맞아 있었다(한 칸 붙기로 추정 — 0.4초 사이를 못 봤다).

## 성공 모습

- iPhone 14에서 엄지로 밀면 스트립이 하루 단위로 이어 흐르고, 오른쪽 끝은 오늘에서 멈춘다.
- 스크롤만 해서는 고른 날·아래 지면이 바뀌지 않는다. 칸을 눌러야 바뀐다.

## 범위 밖

- 본문 밀기를 걷는 것(실기기에서 새 스트립과 함께 써 본 뒤 따로).
- 안드로이드 실기기 확인은 진행 중인 밤샘 시험(갤럭시)이 끝난 뒤.
