# Quickstart — 122 실기기 확인 (SM-S901N dev)

전제: 기기에 옛 `a1`(1,522,796,768 B)과 검증 기록이 있다. Metro 번들만 올린다(모델 보존 — 옛 파일이 시험 대상).

1. 옛 a1 교체: 앱을 열고 쓰기 → 「AI 모듈을 준비해야 해요」 → 다시 받기. `run-as … ls -l files/models`로 옛 파일 삭제·새 파일 생성 확인.
2. R2 받기·이어받기: 받는 도중 `run-as com.a810labs.pocketlog kill -9 <pid>` → 다시 열고 받기. `state.json`의 `doneIndices`가 남은 채 이어지는지, logcat/네트워크에서 Range 요청 확인.
3. md5: 완료 후 `state.json` 검증 기록 `verifiedMd5 == dfc35a88…`, `passed: true`.
4. HF 폴백: 개발 번들에서 `a1.url`을 존재하지 않는 경로로 임시 교체 → 받기 → 예비 경로로 완료(기기 파일 지운 뒤). 되돌린다.
5. 생성: 사진 있는 날 일기 쓰기 → 본문·제목 저장.

## A/B 실측 — 옛 모델 대 새 모델 (2026-11-22, SM-S901N, dev 빌드 + Metro 번들)

122가 앱에서 무엇을 바꿨는지 가린 첫 비교다. 위 기록은 받기·교체·완주만 확인했고 옛 모델과의 글·속도 비교는 없었다. 원문 여섯 편은 [ab-samples.md](ab-samples.md).

**방법**: 같은 코드(`main`, 123 포함)에서 모델 자산과 샘플링만 바꿨다 — 옛 쪽은 `git checkout f60d969^ -- src/models/roster.ts src/inference/sampling.ts`(옛 Q4_K_M 1,522,796,768 B·md5 `d8506380…`, temperature 0.8·top_p 0.95)로 Metro를 다시 띄우자 앱이 첫 실행 받기 화면으로 가서 옛 모델을 스스로 받고 검증했다(약 1분). 날마다 일기 파일을 지우고 Maestro로 그 날을 골라 「쓰기」를 눌러 끝까지 쓰게 했다(`stop-button`이 사라지고 `written-paper`가 서면 끝). 사진 있는 날 11-12(5장)·11-15(6장·장소 1)·11-16(8장·장소 4)을 새 모델 → 옛 모델 순서로 한 번씩 썼다. 자동 쓰기는 끼어들지 않게 잠시 껐다(`auto-diary.json`).

| 항목 | 옛 모델 (11-12 / 11-15 / 11-16) | 새 모델 |
| --- | --- | --- |
| 글자 수 | 487 / 238 / 357 | 285 / 281 / 302 |
| 줄바꿈 | 5 / 4 / 4 | 0 / 0 / 0 |
| 해요체 아닌 문장 | 0 / 0 / 0 | 0 / 0 / 0 |
| 마지막 「주인도 ~했던 것 같아요」 | 0/3 | 3/3 |
| 사진 읽기(초) | 15.5 / 25.4 / 35.7 | 11.0 / 18.5 / 30.1 |
| 본문 쓰기(초) | 57.4 / 40.3 / 60.6 | 30.5 / 35.0 / 45.6 |

**읽은 것**: 새 모델의 차이는 글맛이 아니라 형식과 일관성이다. 한 단락 5~6문장으로 길이가 일정하고 주인 짐작 마무리 문장을 3일 모두 지키며, 사진에서 본 것을 나열한다. 옛 모델은 문단이 나뉘고 길이가 들쭉날쭉하며(11-12는 「오늘 내 눈에는」으로 시작하는 문단이 셋), 「희미한 희망이 담겨 있는 것처럼」·「누군가가 사진을 찍고 있었겠지」처럼 사진에 없는 추측과 일반적인 감상으로 끝나는 날이 많다. 반대로 새 모델은 「~를 렌즈에 담았어요」가 반복돼 기계적으로 읽히고 감상은 옛 모델이 더 풍부하다. 어색한 표현도 남는다(11-12는 「밤」이라 쓰고 「아침이나 저녁 무렵」이라 했고, 11-16은 「벽장 뒤 사다리가 있는 백색 공간」). terrarium EXP-013의 수치(주인 짐작 문장 준수 30%·20% → 100%, 비문 30%·50% → 0%)와 같은 방향이다.

**속도는 단정하지 못한다**: 같은 사진 읽기 모델인데 옛 쪽이 평균 약 28% 더 걸렸다(25.5초 대 19.9초) — 새 모델을 먼저 돌렸으니 기기 온도·순서 영향이 섞였다. 이 오차를 빼면 본문 쓰기의 실제 차이는 10% 안팎일 수 있고, 옛 모델 11-12가 길어(487자) 시간에 섞였다.

**한계**: 3일 1회씩이라 샘플링 무작위성을 못 가른다. 사진과 글을 일일이 대조하지 않아 환각 비율은 재지 않았다. 앱 안의 사진 캡션이 terrarium의 고정 캡션과 다르다. iPhone·모바일 데이터는 안 봤다.

**시험 뒤 상태**: 기기는 새 모델(`dfc35a88…`)을 다시 받아 검증을 통과했고, 일기 세 개와 `auto-diary.json`은 백업으로 되돌렸다. Metro는 껐고 모델 설정 파일의 임시 변경은 되돌려 저장소는 깨끗하다.
