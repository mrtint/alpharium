# Contract: 엔진 load 직렬화 (LD)

- **LD1** `load()` 호출은 도착 순서대로 하나씩 본문을 실행한다. 본문은 지금의 `load()` 본문(같은 캐릭터 재사용·다른 캐릭터 닫기·`releasing` 대기·적재)이다.
- **LD2** 두 호출이 동시에 와도 네이티브 `loader`는 같은 캐릭터에 대해 한 번 불리고, 두 번째 호출은 `{ ok: true, warm: true }`다.
- **LD3** 다른 캐릭터가 뒤따르면 앞 적재가 끝난 뒤 앞 것을 `unload()`하고 연다. 어느 순간에도 열린 컨텍스트는 최대 하나다(E1).
- **LD4** 앞 호출이 실패(`load-failed`·`not-found`)해도 대기열은 막히지 않는다 — 뒤 호출은 새로 `loader`를 시도한다.
- **LD5** `unload()`·`prewarm()`·`generate()`는 대기열을 거치지 않는다(기존 계약 E2·E5·U6 불변).
- **LD6** `stopRequested = false` 초기화(092)는 `load()` **호출 시점(동기)**에 한다 — 종전과 같다. 앞 적재를 기다리는 동안 온 `stop()`은 이 쓰기를 그만두려는 것이라 본문이 시작할 때 지우면 안 된다(106 수렴에서 바로잡음).
