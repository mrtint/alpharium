## iOS 시뮬레이터

쓴 날과 안 쓴 날이 섞인 표본(30일 표본, AGENTS 「도구 사용법」)을 둔 시뮬레이터에서 앱을 열고 시뮬레이터 제어 도구의 `swipe`로 확인한다.

1. 쓴 날 본문에서 오른쪽으로 → 전날, 왼쪽으로 → 다음 날. 주 경계에서 스트립이 따라간다.
2. 오늘에서 왼쪽으로 → 그대로.
3. 캐러셀 위에서 가로로 → 사진만 넘어간다.
4. 본문을 세로로 → 스크롤만.
5. 안 쓴 날의 재료 지면에서 같은 확인.

## iPhone 14

개발 서명 Release 빌드를 설치하고 사람이 한 번 민다(손에 맞는 정도와 세로 스크롤 경합).

## 실측 (2026-11-11, iOS 시뮬레이터 iPhone 17e · iOS 27.0, 개발 서명 아닌 Release 시뮬레이터 빌드)

모델은 `.maestro/ios/_prepare-simulator.yml`로 받았고, 쓴 날 6일치(11/4·6·7·8·9·10 — 사진 2·0·1·0·0·2장, 짧은 글·12문단 긴 글)를 앱 데이터의 `diary/`에 직접 써 두었다(생성하지 않았다). 밀기·스크린샷은 Maestro `swipe`와 `takeScreenshot`으로 했다.

| 확인 | 결과 |
|---|---|
| 오늘(안 쓴 날 재료 지면)에서 왼쪽 | 그대로 |
| 오늘에서 오른쪽 | 11/10(쓴 날)로 이동, 스트립 선택도 따라감 |
| 본문에서 오른쪽 연속 | 11/9 → 11/8 … 11/5(안 쓴 날 재료 지면, 같은 밀기로 이동) → 주 경계에서 스트립이 앞 주로 넘어감 |
| 캐러셀 위 가로 | 사진 1/2 → 2/2 → 1/2, 날은 그대로 |
| 본문에서 왼쪽 | 오늘로 돌아옴 |
| 긴 글에서 세로 끌기 | 스크롤만 되고 날은 그대로 |
| 대각선(거의 가로, 4·8%, 느림) | 날이 넘어감 |
| 대각선(15%, 빠름) / (4%, 빠름) | 날이 넘어감 |
| 가파른 대각선(약 28°, 느림, 스크롤 맨 끝) | 날이 넘어가지도 지면이 움직이지도 않음 — 스크롤이 이기고 끝이라 변화 없음 |
| 세로에 가까운 대각선 | 스크롤이 이김, 날은 그대로 |

- 시뮬레이터의 Maestro 밀기는 직선이고 일정한 속도다. 사람 손의 곡선·가속·두 손가락·한 손 엄지 호는 못 본다 — iPhone 14에서 사람이 한 번 밀어 본다.
- 못 본 것: 쓰는 중(생성이 필요해 시뮬레이터에서는 하지 않았다 — 홈 테스트가 잠근다), VoiceOver(사용자 지정 동작은 jest로만 확인), 안드로이드 전부, 동작 줄이기·큰 글꼴.
- 시뮬레이터 접근은 앱 패널 허용을 받지 못해 `simctl`·Maestro(저장소의 e2e 도구)로 했다.
