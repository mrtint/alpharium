# 검증 안내: 사진 신호 수집

**기능**: 004-photo-signal-collection | **Date**: 2026-08-14

이 기능이 실제로 도는지 확인하는 절차. **기기 없이 도는 것과 실기기가 필요한 것을
가른다** — 건너뛴 실기기 테스트는 통과가 아니다(헌법 원칙 V).

## 실기기 — D1: 「일부 사진만 허용」이 판정되는가

**이것을 가장 먼저 한다. 결과가 명세를 바꿀 수 있다**(research.md §2).

1. 앱을 지우고 다시 깐다(권한 상태를 `undetermined`로 되돌리기 위해).
2. 진단 화면을 연다 → 사진 접근이 `undetermined`인지 본다.
3. 「사진 권한 요청」을 누른다.
4. 안드로이드 창에서 **「사진 및 동영상 선택」**(일부만 허용)을 고르고 두어 장만 고른다.
5. 진단 화면의 사진 접근 값을 본다.

| 보이는 값 | 뜻 | 다음 |
| --- | --- | --- |
| `limited` | 안드로이드가 구분해 준다 | FR-008을 그대로 구현한다 |
| `granted` | **구분되지 않는다** | **명세를 고쳐야 한다** (아래) |

**`granted`로 보이면**: 「일부만 허용」을 「전체 허용」과 구분할 수 없다는 뜻이다. 그러면
FR-008을 지킬 방법이 없다. 발견한 사실을 그대로 적고, 판정을 어떻게 할지 다시 정한다 —
그럴듯한 판정을 지어내지 않는다. `PhotoObservation.complete`가 이미 있으므로 그 자리에
"전부인지 알 수 없다"를 담는 길이 열려 있다.

**둘 중 무엇이든 결과를 research.md에 실측으로 적는다** — 언제 어느 기기에서 쟀는지 함께.

---

## 실기기 — D2: 실제 사진이 신호에 나타난다 (SC-008)

1. 권한을 **전체 허용**으로 바꾼다(설정 → 앱 → 권한).
2. 오늘 사진을 두어 장 찍는다. 한 장은 위치를 켜고, 한 장은 끄고.
3. 진단 화면에서 오늘의 신호를 조회한다.

**기대**:

- `photos`가 `known`이고 방금 찍은 장수가 맞다
- 사진 순서가 찍힌 시각 순이다
- `places`가 `known`이고 `photosWithLocation`이 위치를 켜고 찍은 장수와 맞다
- `steps`·`battery`·`connectivity`가 `unknown`이고 이유가 서로 다르다

---

## 실기기 — D3: 권한 허용 전후로 판정이 바뀐다 (SC-008a)

1. 설정에서 사진 권한을 **거절**로 바꾼다.
2. 신호를 조회한다 → `photos`가 `unknown`이어야 한다. **`none`이면 실패다.**
3. 권한을 다시 허용한다.
4. 신호를 조회한다 → `photos`가 `known` 또는 `none`으로 바뀌어야 한다.

**2번이 이 기능의 핵심 검증이다.** 여기서 `none`이 나오면 일기가 거짓을 쓰게 된다(SC-002).

---

## 실기기 — D4: 상한이 적절한가 (research.md §7)

사진이 많은 날(200장 이상)이 있으면 그 하루를 조회하고 걸리는 시간을 본다. 없으면 건너뛴다.

**보는 것**: 좌표를 200번 묻는 데 걸리는 시간. 체감상 오래 걸리면 상한을 낮추거나, 좌표를
전부 묻지 않는 쪽으로 바꾼다. **잰 값을 research.md에 적는다** — 지금 200은 짐작이다.

---

## 실기기 — D5: 100m가 적절한가 (research.md §4)

집에서 찍은 사진 여러 장이 **한 자리**로 세어지는지 본다. 여러 자리로 갈리면 100m가 작다.

**잰 값을 적는다.** 지금 100m는 짐작이며 실측이 아니다(FR-013h).

## 무엇을 보면 실패인가

| 증상 | 무엇이 깨졌는가 |
| --- | --- |
| 권한 거절 상태에서 `photos`가 `none` | **FR-007, SC-002.** 가장 심각하다 |
| 좌표 권한이 없을 때 `photos`가 `unknown` | FR-013a, SC-004 |
| 좌표 권한이 없을 때 신호 조회가 예외로 죽는다 | FR-012 — `locationOf`가 안 감싸였다 |
| 진단 화면을 열자마자 권한 창이 뜬다 | FR-011 |
| 03:59과 04:01 사진이 같은 하루에 | FR-002 |
| 상한을 넘겼는데 `complete`가 `true` | FR-014a |
| 집에서 찍은 사진이 여러 자리로 | FR-013f — D5로 값을 조정 |

## 이 기능이 끝나도 안 되는 것

- **일기는 나오지 않는다.** `generate()`는 여전히 `not-implemented`이고, 파이프라인은
  `generation`에서 멈춘다. 다만 이제 `signals` 단계는 **진짜 값**을 통과시킨다.
- **사진의 내용을 보지 않는다.** 몇 시에 몇 장인지만 안다.
- **걸음·배터리·연결은 `unknown`이다.** 그것이 이 기능의 결론이다.
- **캐릭터에 이름과 설명이 없다.** 003과 같다.
