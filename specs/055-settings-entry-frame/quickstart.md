# Quickstart: 설정 진입과 화면 틀 (055) — 검증 안내

## 기기 없이

```bash
npm run test:logic   # permission-tags · version 순수 함수
npm run test:ui      # 진입점 · 겹 · 설정 틀 · 이름 바꾸기 · 모듈 다시 받기 배선
npm test && npm run lint
```

계약 ID는 [contracts/settings-stack.md](contracts/settings-stack.md). jest는 배선만 본다 — 아래 실기기 단계를 건너뛰면 통과가 아니다(원칙 V).

## 실기기 (dev 빌드만 — release 하지 않는다)

전제(AGENTS 「도구 사용법」): `EXPO_PUBLIC_APP_ENV=dev npx expo start --dev-client`, `adb reverse tcp:8081 tcp:8081`, 잠금 해제.
`expo-application`을 직접 의존성으로 올렸으므로 debug APK를 다시 빌드해 설치한다(`npx expo run:android`). **모델·일기를 보존한다** — `pm clear` 하지 않는다.

| # | 단계 | 기대 |
| --- | --- | --- |
| Q1 | 안 쓴 날 홈에서 점 세 개 → 설정 | 오른쪽에서 밀려 들어온다(`screenrecord` 30fps 프레임으로 본다 — `MSYS_NO_PATHCONV=1`). 묶음 넷·문구 원문 |
| Q2 | 쓴 날 지면을 내려 스트립을 접은 채 → 설정 → 「‹ 일기」 | 같은 날·같은 스크롤·접힘 그대로 |
| Q3 | 같은 상태에서 → 설정 → 시스템 뒤로 | Q2와 같다. 홈에서 한 번 더 뒤로 → 지금처럼(앱이 배경으로) |
| Q4 | ★ 쓰는 중 → 설정 → 시스템 뒤로 → 다시 설정 → 「‹ 일기」 | 쓰기가 멈추지 않고 끝나 쓴 날이 보인다(SC-002). 설정 안의 뒤로가 「그만두기」로 동작하지 않는다 |
| Q5 | 쓰는 중 → 설정 → 이름 바꾸기 → 저장 → 쓰기 완료 | 방금 일기는 옛 이름, 다음 일기는 새 이름 |
| Q6 | 이름 바꾸기에서 입력을 모두 지움 | 「저장」 흐림·눌리지 않음. 키보드 위에 입력줄과 저장이 보인다(047 edge-to-edge) |
| Q7 | 위치 권한을 끈 채 설정 → 위치 「허용 안 함」 → 행 누름 → 앱 정보 → 위치 허용 → 돌아옴 | 다른 조작 없이 「허용됨」(SC-005) |
| Q8 | 사진 「선택한 사진만」 허용 | 사진 「일부 허용」(회색 테두리) |
| Q9 | 배터리 행 누름 | 앱 정보 화면(024의 「배터리 사용 관리」 목록이 아니다) |
| Q10 | 버전 행 | 「1.0.0 (9)」(설치본의 versionCode) |
| Q11 | TalkBack을 켜고 설정을 연 채 훑기 | 홈 요소가 읽히지 않는다. 점 세 개는 「설정」 |
| Q12 | 글꼴 크기 2.0배 | 권한 행 꼬리표·배터리 보조 줄이 잘리지 않는다 |
| Q13 | 쓰는 중 설정 지면 스크롤 | 혼잣말 교체 때문에 버벅이는지 눈으로 본다(미확인 잔여 판정) |

「모듈 다시 받기」(FR-030)는 세션 도중 모델을 잃어야 닿는다 — 유도가 어려우면 계약 테스트(D1~D4)로 갈음하고 미확인 잔여에 적는다.
