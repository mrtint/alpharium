# 제자리 쓰기 — 설계 (홈 UI/UX 개편 조각, 분해 설계 §3.4 · 보드 2b·2i)

입력: `docs/superpowers/specs/2026-09-26-home-uiux-decomposition-design.md` §3.4. 이 문서는 그 절의 문구·수치·코드 대조를 그대로 따르고, 아래 구조 결정만 더한다.

## 목적
쓰는 동안 화면을 떠나지 않는다. 실패는 토스트 한 줄로 알리고 쓰기 전 상태로 돌아간다.

## 구조
1. **화면**: `DiaryHomeScreen`의 `writing`(전체 화면)을 홈 렌더 안의 상태로 바꾼다. 헤더·스트립은 그대로, 지면 자리만 바뀐다.
   - 헤더 상태 줄 「쓰는 중」(13/600, accent).
   - 스트립 불투명도 .35, 탭·스와이프·헤더 날짜 탭은 이벤트를 받지 않는다(`pointerEvents="none"` + 접근성 숨김). 052 접힘은 쓰는 중 꺼 둔다.
   - 지면은 배경색 위(2b 마크업): 여백 32/20/120, 간격 14. 머리말 「쓰는 중」 11/600 accent 대문자 간격 .1em, 혼잣말 24/700 줄높이 1.35 자간 -.01em, 「{이름}이 쓰고 있어요. 진행률은 세지 않아요.」 13 보조색(조사는 `particle.ts`).
   - 하단 바: `text`(검정) 전폭 「그만두기」 17/800, 최소 높이 64, 글자 `bg`. 051·053의 하단 바 자리를 쓴다.
2. **쓰기 전 상태 보존**: 고른 날·그 날 일기 요약을 그대로 들고, 그만두기·실패 시 `writing`만 벗긴다(처음 쓰던 날 → 안 쓴 날 1d, 다시 쓰던 날 → 기존 일기 2c). 저장은 끝에만 일어나므로 새 글은 남지 않는다(`pipeline.ts:351`). 현재 `cancel()`의 `toList` 이동을 이 복귀로 바꾼다.
3. **토스트**: 좌우 12, 하단 바 위 12(보드 bottom 110 = 바 64 + safe area 34 + 12), 최소 높이 48, 안쪽 여백 12/16, 배경 `text`, 글자 `bg` 14/600, 그림자 `0 8px 24px rgba(0,0,0,.18)`, 왼쪽 accent 6×6. 3초 뒤 사라지고 아래로 쓸어 닫는다. reanimated 슬라이드 + gesture-handler v2 Pan(`runOnJS`), 판정은 순수 함수. 새 의존성 없음. 문구 「일기를 쓰지 못했어요. 다시 써 볼 수 있어요.」, 이유·모델·오류 코드 미노출, 버튼 없음.
4. **독백**: 보드 `monologue1`은 `monologue.ts:67`과 글자 같음 — 문안 풀 재사용. 교체 방식은 clarify.
5. **실패 분류**: 다시 쓰면 풀릴 실패만 토스트. 사용자가 조치해야 하는 실패(준비 안 됨·캐릭터 없음)에 「다시 써 볼 수 있어요」 거짓 안내 금지. 분리 방식은 clarify.

## clarify로 넘기는 질문
1. 실패 두 부류 분리 방식
2. 독백 교체: 039 타자기 유지 vs 보드 페이드
3. 완성 직후 연출: 038 타자기, 「저장 실패」·「덮어썼다」 안내의 행방
4. 헤더 날짜 잠금 여부, 뒤로 가기=그만두기 유지 여부

## 검증
- 기기 없는 테스트(배선): 쓰는 중 날 이동 잠금, 그만두기·실패 뒤 복귀 상태(처음/다시), 토스트 3초(가짜 시계), 토스트에 이유 문자열 미유출, KO 원문 글자 단위 계약, 수치 계약.
- 움직임(페이드·토스트 슬라이드·쓸어 닫기)은 jest가 못 잡는다 → 스펙에 「실기기 육안 검증」을 따로 적는다. dev 빌드 1회, `pm clear` 없이, 화면 녹화 프레임 확인.
- Maestro: `maestro test`로 직접. `diary-user-path`, `generate-diary`, `past-day-diary`, `photo-selection-over-limit`, `writing-flow-simplified`, `writing-monologue`, `writing-monologue-expansion`을 같은 스펙에서 고치고 새 흐름은 `FLOWS`에 등록.

## 범위 밖
페르소나 어미 변형, 설정·개발자 진입점, 쓰기 전 판정 `decideMaterial`(053, 무변경 — 그 뒤에서 이어 붙는다).

## 설계 단계 대조
2b·2i 마크업의 flex·position·transform을 읽었다. transform 없음, 토스트·하단 바는 `position:absolute`(하단 기준), 인터랙션 메모와 어긋남 없음.
