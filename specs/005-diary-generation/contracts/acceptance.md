# 계약: 출력 판정

**Feature**: 005-diary-generation | **모듈**: `src/diary/acceptance.ts`

**기기를 모른다.** 문자열과 불리언 몇 개만 보므로 전부 기기 없이 검증된다.

---

## 이 자리가 무엇을 지키는가

**여기가 헌법 원칙 I의 마지막 방어선이자, 원칙 IV가 가장 쉽게 무너지는 자리다.**

002가 `GenerationFailure`에 `text`를 두지 않아 **타입에서** 막았다. 이 모듈이 **실행에서**
막는다. 둘이 함께 있어야 「그럴듯한 무언가」가 일기 자리에 들어가는 것을 실제로 못 한다.

동시에 이 모듈은 **판정 코드가 채점 코드로 자라는 압력을 받는 유일한 자리다.** 유사도를
재고 싶어지고, 품질을 보고 싶어지고, 임계값을 두고 싶어진다. **그 압력에 대한 방어가
계약으로 못 박혀야 한다** — 그것이 이 저장소를 되돌리게 한 실패의 재발 방지다(원칙 IV).

---

## 함수

```
judge(text: string, ending: Ending, character: Character, instructions: string[])
  → Verdict
```

**`ending`을 인자로 받는 이유**: 「중간에 잘렸는가」는 문자열을 봐서는 모른다. 문장 부호로
추측하면 그것이 휴리스틱이고 임계값의 시작이다. **모듈이 사실을 주므로 짐작할 필요가
없다**(research §1) — 그 사실을 받는다.

**`instructions`를 인자로 받는 이유**: 되뱉기 판정이 프롬프트의 고정 줄과 비교해야 한다
(prompt.md P7). 모듈이 스스로 프롬프트를 만들면 프롬프트가 두 곳에 있게 된다(FR-013b 위반).

---

## 입력: `Ending`

생성이 **어떻게 끝났는가**. `llama.rn`이 주는 사실을 그대로 옮긴 것이지 우리가 판단한
것이 아니다.

```
kind: "eos"          모델이 스스로 끝냈다      → 정상
kind: "length"       길이 한도에 걸렸다        → 잘림
kind: "context"      컨텍스트가 모자랐다      → 잘림
kind: "interrupted"  끊겼다 (앱이 벗어남)     → 잘림
kind: "timeout"      시간 한도를 넘었다        → 잘림
```

**`eos` 하나만 정상이다.** 나머지 넷은 전부 「글이 끝나지 않았다」이며 FR-016d·FR-021c가
거부를 요구한다.

**왜 넷을 뭉개지 않는가**: 사용자에게 옮길 말이 다르기 때문이다(FR-017d). `length`는 다시
시도할 만하고, `interrupted`는 앱을 떠나서 그런 것이며, `timeout`은 기기가 버거운 것이다.
003이 `ModelReadiness`를 넷으로 가른 것과 같은 이유다.

---

## 출력: `Verdict`

```
{ ok: true }
{ ok: false, why: RejectReason }
```

**`Verdict`가 텍스트를 담지 않는다**(FR-017c). 거부된 글이 실려 나가면 그것이 `text`가
새는 경로가 된다 — 통과한 글은 부르는 쪽이 이미 들고 있으므로 돌려줄 이유도 없다.

**`Verdict`가 수를 담지 않는다**(FR-018c). 길이·비율·점수 어느 것도 없다. 수가 담기면
그것으로 모델을 견주게 되고, 그 순간 원칙 IV가 무너진다.

### `RejectReason` — **넷뿐이다** (FR-018b)

```
"empty"        비었거나 공백뿐        (FR-016a)
"echo"         프롬프트 문장이 그대로 (FR-016b-1)
"language"     캐릭터의 언어가 아님   (FR-016c)
"unfinished"   글이 끝나지 않았음     (FR-016d, FR-021c)
```

**이 목록에 갈래를 더하려면 원칙 IV를 어기지 않는지 먼저 따져야 한다**(FR-018b).
"너무 짧다"·"반복이 많다"·"일기 같지 않다"는 전부 품질 판단이며 여기 들어올 수 없다.

**상한이 계약에 있는 이유**: 판정은 한 번에 무너지지 않는다. 갈래 하나가 그럴듯한
이유로 늘고, 다음에 또 하나가 늘고, 어느 순간 채점기가 되어 있다. **넷이라는 수를 못
박아 두면 다섯 번째를 넣을 때 반드시 이 문서를 다시 읽게 된다.**

## 판정 규칙

### A1. 빈 글 (`empty`)

공백을 걷어낸 뒤 비어 있으면 거부. **길이 하한을 두지 않는다** — 하한은 임계값이고,
"몇 자 이상이어야 일기인가"는 품질 판단이다.

### A2. 되뱉기 (`echo`) — FR-016b-1

`instructions`의 각 줄에 대해, **의미 있는 길이의 줄이 출력에 그대로 들어 있으면** 거부.

- **부분 문자열 포함 여부만 본다.** 불리언이다
- **유사도를 재지 않는다**(FR-016b-2). 비율·거리·n-gram 전부 금지
- **최소 길이는 짐작이다**(원칙 V). 너무 짧으면 흔한 표현에 걸리고 너무 길면 부분
  되뱉기를 놓친다. **주석에 짐작임을 남기고** 실기기에서 오탐이 보이면 고친다

**왜 임계값이 아닌가**: 최소 길이는 **무엇을 비교할지 고르는 값**이지 통과·거부를 가르는
점수가 아니다. 비교 대상이 정해진 뒤의 판정은 "들어 있다/없다"뿐이다. 이 구분이 흐려지면
FR-016b-2가 무의미해지므로 계약에 적어 둔다.

### A3. 언어 (`language`) — FR-016c

| 캐릭터 | 통과 조건 |
| --- | --- |
| `quiet`·`narrative`·`imaginative` | 한글 음절이 **있다** |
| `chinese` | 한자가 **있고** 한글이 **없다** |
| `english` | 라틴 문자가 **있고** 한글·한자가 **없다** |

**불리언의 조합이지 비율이 아니다.** "한국어다움 70%"를 재지 않는다.

**비대칭이 의도적이다**: 한국어 캐릭터는 다른 문자를 금지하지 않는다 — 고유명사와 영어
단어가 섞이는 것은 정상이다. 반대로 `chinese`·`english`는 한글을 금지한다. **헌법이 그
방향만 못 박았기 때문이다**("한국어로는 쓰지 않는다 MUST NOT"). 헌법이 말하지 않은 것을
우리가 더 금지하지 않는다.

### A4. 끝나지 않음 (`unfinished`) — FR-016d, FR-021c

`ending.kind !== "eos"`이면 거부. **문자열을 보지 않는다.**

---

## 순서가 정해져 있다

```
1. unfinished  ← 가장 먼저
2. empty
3. echo
4. language
```

**`unfinished`가 첫째인 이유가 중요하다.** 끊긴 결과에도 거기까지 생성된 `text`가 들어
있다(research §2). 다른 판정을 먼저 하면 끊긴 글이 나머지를 통과할 수 있고, 그러면 순서에
의존하는 취약한 방어가 된다. **끝나지 않은 글은 내용을 볼 필요가 없다.**

순서가 정해져 있으면 **같은 입력에 항상 같은 `why`가 나온다.** 테스트가 안정되고, 사용자가
보는 말도 안정된다.

---

## 금지

- **거부된 글을 어디로도 내보내지 않는다**(FR-017c) — `Verdict`에도, 로그에도, 진단에도
- **수·점수·비율을 담지 않는다**(FR-018c)
- **임계값으로 통과를 가르지 않는다**(FR-016b-2)
- **갈래를 넷보다 늘리지 않는다**(FR-018b) — 늘리려면 이 문서를 먼저 고친다
- **글을 고치지 않는다**(FR-017). 잘라내기·다듬기·재작성 금지. 판정은 통과/거부만 한다
- **화자 뒤집힘·사실 단언을 판정하지 않는다**(FR-018). 의미를 읽어야 하는 것이며 프롬프트로
  막고 사람이 읽어 확인한다

## 검증 (기기 불필요)

| # | 무엇 | 어떻게 |
| --- | --- | --- |
| A-1 | 빈 글 거부 | `""`, `"   "`, `"\n\n"` → `empty` |
| A-2 | 되뱉기 거부 | 프롬프트 고정 줄을 담은 출력 → `echo` |
| A-2b | 오탐 없음 | 정상 일기가 `echo`로 거부되지 않는다 |
| A-3 | 언어 판정 | 다섯 캐릭터 × 한국어/중국어/영어 출력 조합 |
| A-4 | 끝나지 않음 | `length`/`context`/`interrupted`/`timeout` → `unfinished` |
| A-5 | **순서** | 끊겼고 **동시에** 되뱉은 글 → `unfinished`(`echo`가 아니다) |
| A-6 | 통과 | 정상 일기 + `eos` → `ok: true` |
| A-7 | **갈래 수** | `RejectReason`이 넷이다 — 늘면 테스트가 깨진다 |
| A-8 | **수가 없다** | `Verdict`에 number 필드가 없다 |

**A-7과 A-8이 원칙 IV의 자동 방어다.** 사람이 리뷰에서 잡는 것에 기대지 않는다.
