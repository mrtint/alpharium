# 쓴 날 하루 동선 목록 접기 — 설계 (경량, 133)

**목적**: 방문한 곳이 많은 날 쓴 날 지면 맨 아래 동선 범례가 길다. 소유자 방향(2026-11-24·26)대로 요약해 접는다.

**수용 기준**
1. 기본 접힘: 사진이 가장 많은 자리(동률이면 번호 작은 자리)의 대표 줄 「서울숲」(이름만, 이름 있는 자리 중에서 고르고 없으면 「N곳 펼치기」만) + 「외 N곳 펼치기」(N = 전체 자리 − 1, 1곳이면 버튼 없음).
2. 펼치면 지금 목록 전체 + 「접기」, 접으면 요약으로 돌아간다.
3. 1곳·동률·12곳 넘음 경계를 테스트로 잠근다.

**결정**
- 처음 보일 곳 수 N 같은 고정값은 두지 않는다 — 요약은 대표 한 곳(소유자).
- 지도·도식·합침은 손대지 않는다(소유자).
- 펼침은 부품 상태로만 두고 날 넘김 뒤 접힘(저장 없음).
- 사진 수는 `RouteItem.photos`로 `SavedPlace.photoCount`에서 옮긴다.
