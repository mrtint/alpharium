# 안내 문구 G1 — 실기기 확인

스펙 Assumptions의 「실기기 확인 대기」(글꼴 1.0배·2.0배에서 잘리지 않는지, 배포된 지원 페이지)를 본 기록이다. PR #224는 클라우드 세션이라 기기 확인 없이 머지됐다.

## 배포된 지원 페이지 (2026-11-10)

`https://mrtint.github.io/alpharium/support/`를 받아 저장소 `site/support/index.html`과 줄 끝 공백만 빼고 비교했다 — 같다. iPhone 저절로 써 두기 줄(「iPhone은 충전 중일 때 저절로 써 둘 수 있고, 언제 쓸지는 iPhone이 정합니다…」)이 배포돼 있다.

## 갤럭시 SM-S901N (2026-11-10, dev 빌드 + Metro 번들)

**방법**: 첫 실행 플래그를 되돌리고(`completed:false`·`downloadConsented:false`) 사진 모델 `v2.bin`(약 100MB)을 지워 동의 → 진행 슬라이드를 다시 띄웠다(나머지 모델은 110의 검증 기록으로 다시 받지 않았다). Maestro로 스플래시·동의·슬라이드 1·슬라이드 4(1에서 오른쪽으로 밀면 순환해 4)를 찍었다. 글꼴은 `settings put system font_scale` 1.0과 2.0. 받은 `v2.bin`은 검증을 통과했다.

| 자리                                | 문구                                                                           | 1.0배                 | 2.0배                            |
| ----------------------------------- | ------------------------------------------------------------------------------ | --------------------- | -------------------------------- |
| 스플래시 캡션 `welcome.logoCaption` | AI가 쓰는 일기                                                                 | 한 줄, 잘림 없음      | 한 줄, 잘림 없음                 |
| 슬라이드 1 제목·본문                | AI가 쓰는 일기 / 주인님의 하루를 글로 남겨요. 실수할 때도 있지만요             | 제목 한 줄·본문 한 줄 | 제목 한 줄·본문 두 줄, 잘림 없음 |
| 슬라이드 4 제목·본문                | 사진과 일기는 서버로 보내지 않아요 / 일기를 쓰는 AI는 이 휴대폰 안에서 돌아요. | 제목 한 줄·본문 한 줄 | 제목 두 줄·본문 두 줄, 잘림 없음 |

진행 막대·「다운로드 중이에요」 줄도 2.0배에서 겹치지 않았다.

## iPhone 14 (2026-11-10, 개발 서명 Release 빌드, iOS 27.0.1)

**방법**: 측정용 빌드(스플래시를 20초로 늘림 — 스크린숏이 한 장에 약 2초라 1.5초 스플래시를 못 잡는다, 측정 뒤 걷음)를 깔고 첫 실행 플래그를 되돌린 뒤 사진 모델 `v1.bin`(약 380MB)을 지워 동의 → 슬라이드를 다시 띄웠다. 사람이 앱을 조작하고 맥이 `pymobiledevice3 developer dvt screenshot`으로 계속 찍었다. 큰 글꼴은 설정 「더 큰 접근성 크기」로 켰고, 같은 글자의 폭을 기본 크기와 비교하면 **약 1.9배**다(AGENTS의 `accessibility-large` ≈1.94배 근처).

| 자리                   | 기본 크기         | 약 1.9배                                                                                                  |
| ---------------------- | ----------------- | --------------------------------------------------------------------------------------------------------- |
| 스플래시 캡션          | 한 줄, 잘림 없음  | 한 줄, 잘림 없음 — 다만 브랜드 제목 「Pocketlog」가 낱말 가운데서 「Pocketl / og」로 끊긴다(G1 문구 아님) |
| 슬라이드 1             | 제목·본문 한 줄씩 | 제목 한 줄·본문 세 줄, 잘림 없음                                                                          |
| 슬라이드 2·3 (G1 아님) | 본문 두 줄        | **본문 둘째 줄이 진행 막대에 가려 잘린다**                                                                |
| 슬라이드 4             | 제목·본문 한 줄씩 | **제목이 세 줄이 되고 본문은 윗부분 조각만 보인다 — 읽을 수 없다**                                        |

갤럭시 2.0배에서 본 자리(스플래시·슬라이드 1·4)는 잘리지 않았다 — 슬라이드 2·3은 갤럭시 2.0배에서 찍지 않았다. 안드로이드 14+의 비선형 글꼴 배율이 큰 글자를 덜 키우는 것으로 보인다(추정 — 재지 않았다).

**판정**: 기본 크기와 갤럭시 2.0배는 통과. **iPhone 약 1.9배에서 슬라이드 2~4의 본문이 잘린다** — 문구(G1)가 아니라 슬라이드 화면의 고정 배치(그림 자리 + 글 영역 높이) 문제다. 고칠지는 소유자가 정한다(후보: 제약 띠처럼 글꼴 배율 상한을 두기, 그림 자리를 줄이기, 글 영역을 스크롤되게 하기).
