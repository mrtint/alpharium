## 목적

쓴 날을 읽는 동안 스트립을 접어 지면을 넓힌다. 끝에 닿았을 때만 「다시 쓰기」를 올리는 것은 051이 이미 한다.

## 보드에서 읽은 사실 (마크업·스크립트)

- `5b` 스크립트 `onPaperScroll`:
  - `end = y + clientHeight >= scrollHeight - 4` → `atEnd` (스크롤 사건에서만 다시 잰다)
  - `up = y < lastY`
  - 접힘: `!collapsed && y > 8 && !up`
  - 펼침: `collapsed && up && y <= 2`
  - 300ms 디바운스(`_t`) — 시안용, 확정값 아님(분해 설계 §3.6)
- `expandStrip`은 날짜 줄 div 전체의 `onClick`이다. 펼친 상태의 탭 → `2j`는 메모에만 있다(시안은 구현 안 함).
- 스트립 래퍼: `max-height 180px→0` `.24s ease-out`, `opacity 1→0` `.18s ease-out`, `overflow:hidden`.
  스트립 위 여백 `margin-top:18`은 **래퍼 안**이라 함께 접힌다. 지면 위 여백(16)은 남는다.
- ▾: 날짜 줄 오른쪽 `flex:none; width:28`, 14/700, `padding-bottom:2`, 자리는 늘 있고 불투명도만 0↔1(.24s).
- 날짜·요일·제목 크기(62·16·15)는 접혀도 그대로다(`hdNum`·`hdDow`·`hdTitle` 고정).
- `5a` ②③④의 점선 강조 상자는 월 라벨 + 날짜 줄(높이 92)을 두른다. 메모는 「높이 44px 전체가 탭 영역」 — 둘이 다르다(clarify).

## 결정 (브레인스토밍, 저장소 소유자 승인 2026-09-29)

**접근 A — 잰 높이를 reanimated로 접는다.**

1. 스트립(과 그 위 여백 18)을 감싼 래퍼의 높이를 `onLayout`으로 잰 자연 높이 → 0으로 240ms ease-out,
   불투명도 1 → 0을 180ms로 옮긴다. 보드의 180은 CSS `max-height`의 상한이지 스트립 높이가 아니다 —
   180에서 줄이면 실제 높이(약 70)까지 내려오는 동안 움직임이 없어 보인다. 그래서 잰 높이를 쓴다.
   `overflow:hidden`. 지면은 `flex:1`이라 늘어난 자리를 채운다. 새 의존성 없음.
   (대안 B: translateY로 올리고 지면을 겹쳐 끌어올림 — 지면의 보이는 높이와 끝 판정이 어긋남.
   대안 C: `LayoutAnimation` — 새 아키텍처 안드로이드 동작·240/180 분리 제어가 불확실.)
2. **판정은 순수 함수로 뗀다**(`src/app/` 쪽, `written-day.ts`와 같은 계열). 이전 상태(접힘, 직전 y)와
   새 y로 다음 접힘 상태를 준다. 경계값 8·2·4와 방향을 기기 없는 테스트로 잠근다.
3. **디바운스를 두지 않는다.** 8과 2 사이의 간격이 되튐을 막는다.
4. **접으면 스크롤할 것이 없어지는 본문은 접지 않는다**(보드에 없는 규칙). 내용 높이 − (보이는 높이 +
   스트립 높이) ≤ 8이면 접지 않는다. 접자마자 지면이 늘어 스크롤이 0으로 눌리고 곧바로 펼쳐지는
   깜빡임을 막는다.
5. **끝 판정은 스크롤 사건·내용 크기 변화·처음 잰 순간에만 한다**(5b와 같다). 접힘·펼침으로 지면 높이가 바뀌어도
   바 상태를 다시 판정하지 않는다 — `5a` ④ 「읽던 위치·하단 바 상태는 그대로」.
6. ▾는 쓴 날의 날짜 줄 오른쪽 28칸, 접히면 페이드인(240ms).
7. 누름: 접힌 상태의 날짜 줄 탭은 펼치기만 한다. 펼친 상태는 050 그대로(큰 숫자·요일 → `2j`).
   이 둘의 계약(050 CAL1과의 관계)을 이 조각의 contracts에 적는다.
8. 접힌 동안 스트립은 누를 수도 넘길 수도 없고 접근성 트리에서 빠진다.
9. 안 쓴 날의 화면은 바꾸지 않는다.

## clarify로 넘길 것

1. 안 쓴 날에도 스크롤이 생기면(큰 글꼴·작은 화면) 어떻게 하는가.
2. 접힌 날짜 줄 탭 영역 44px의 범위(날짜 줄만 / 월 라벨 포함 / 제목 포함).
3. 날을 바꾸면 접힘 상태를 어떻게 하는가(051은 날마다 지면을 새로 마운트해 맨 위에서 시작).
4. 접힌 동안 스트립 스와이프(049)와 달력 열기.
5. 거부 권한 안내(Notices, 헤더의 스트립 아래)를 스트립과 함께 접는가.

(「짧으면 처음부터 보임」의 측정은 051이 `onLayout` + `onContentSizeChange`로 정했으므로 질문하지 않는다.)
