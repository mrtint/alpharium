# Quickstart — 092 실기기

전제: iPhone 14(iOS 27.0.1), **충전기·선 없음**(무선 연결이 이 맥의 Wi-Fi에서 안 서서 배터리 회차는 사람이 앱을 조작하고, 원인 가르기는 유선으로 했다), 개발 환경 Release 빌드 설치(새 네이티브 모듈 — prebuild 필요).

1. 사진 있는 안 쓴 날을 고른다(091 시드). 홈에서 「쓰기」 → 5초 안에 홈 화면으로 나간다.
2. 잠금 화면·알림 센터의 진행 표시를 본다(단계 문구, 막대가 움직이는가).
3. 완성 알림을 기다린다. 앱 컨테이너의 `Documents/diary/<날짜>.json`, `systemCrashLogs`의 `cpu_resource_fatal`을 읽는다.
4. 같은 절차를 앱에 머문 채 한 번(SC-003 시간 비교), 쓸 차례 알림 누름으로 한 번.
5. 이어 쓰는 중 진행 표시에서 취소 → 「도중에 끊김」 기록·앱 생존.

## 실측

2026-10-21, iPhone 14 · iOS 27.0.1 · 개발 환경 Release(Xcode 27 SDK — 아래 「빌드 함정」), 10월 19일(사진 6장), 앱 열기 자동 쓰기(057)로 시작.

**판정**: SC-001(충전 없이 앱을 나가도 저장·완성 알림) — 배터리 2에서 봤다(표본 1). SC-002(단계 문구·막대 세 번 이상) — 보고 수백 번, 사람이 진행 표시를 봤다. SC-003(앱에 머문 쓰기 ≤ 114초) — L 51초. FR-006(만료 → 「도중에 끊김」) — N. quickstart 4(쓸 차례 알림 누름)는 따로 누르지 않았다 — 알림은 그 날로 열려 057이 시작하는데, 위 회차가 모두 057로 시작했다.

**알게 된 것**:
- **★ 이어 하기는 보고 횟수가 아니라 `completedUnitCount`가 오르는가를 본다.** dasd `ProgressTracker`가 처음에 보고 간격을 익히고(`BaselineWarmup`), 그 뒤 값이 오르지 않는 공백이 익힌 간격보다 길면 「Task has not reported progress within expected cadence, marking stalled」로 끝낸다(약 35~39초에서 봤다). 남은 몫에 다가가는 막대를 1000칸으로 두면 끝 무렵 걸음이 한 칸 아래로 줄어 값이 멈춘다 — 칸을 1,000,000으로 늘리고 보고마다 한 칸 이상 올린다.
- **앱 밖에서는 iOS가 CPU를 크게 줄인다** — 사진 한 장 앞 4.5초 → 밖 50~58초(스레드 기본)·28~32초(스레드 2). 파일 매핑된 모델은 앱 밖에서 생성이 0.17토큰/초까지 떨어졌고 메모리에 올리면(mlock·`use_mmap: false`) 약 7배 빨랐다(모델 데이터가 밀려나 다시 읽힌다는 짐작).
- **작은 토막의 프롬프트 읽기는 토큰당 비용이 크다** — 한 번에 613토큰은 9.2ms/토큰, 5~38토큰 토막은 30~100ms/토큰. 그래서 토막 길이를 토막마다 앱 상태로 고른다(앞 240자·밖 24자).
- 진행 표시에서 사람이 취소한 것과 시스템이 끝낸 것은 같은 만료 처리기로 와서 가를 수 없다 — 둘 다 「도중에 끊김」이고 홈은 토스트를 띄운다.
- 그만두기·만료로 끊긴 쓰기의 막대는 남은 채 실패로 닫힌다. 앱을 다시 열면 057이 그 날을 다시 쓴다.

**빌드 함정**: Xcode 27(iOS 27 SDK)로 그대로 빌드하면 UIScene을 쓰지 않는 앱이 실행 즉시 `UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption` SIGTRAP으로 죽는다. 측정용으로만 `npm install --no-save expo@57.0.23 expo-build-properties@57.0.20` + `app.json`에 `["expo-build-properties",{"ios":{"enableSceneSupport":true}}]`를 넣었다가 되돌렸다(커밋 안 함). CI는 Xcode 26.6이라 영향이 없다 — 로드맵 「Xcode 27 UIScene 대응」.

**미확인**: 충전 없는 회차는 표본 1, 다른 iPhone·iOS 26.x, 사진 8장 날, 화면을 끈 채 오래 둔 경우, 시스템이 자원 부족으로 끊는 경우, TestFlight 빌드.
