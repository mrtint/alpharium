# 계약: 조사 선택 (particle.ts)

**대상**: `src/diary/particle.ts`
**관련 요구사항**: ~~FR-003a, SC-002a~~ (2026-08-23 철회 — 아래 참조)

---

**[2026-08-23]** 문구 검수 과정에서 사용자가 로드 단계 문구에 캐릭터
이름을 넣는 기능 자체를 철회했다 — `monologue.ts`는 더 이상 이 함수를
import하지 않는다. `particleFor()`는 함수와 이 계약 모두 코드에 남아
있으며 아래 판정 규칙·불변식은 여전히 유효하다(다른 화면이 조사 선택을
필요로 하면 재사용 가능). 다만 "로드 단계 문구에 쓰인다"는 원래의 사용
목적은 더 이상 성립하지 않는다.

## 진입점

```ts
export function particleFor(name: string): "이" | "가"
```

## 판정 규칙

이름의 마지막 글자가 한글 완성형(U+AC00~U+D7A3, "가"~"힣") 범위에 있으면
`(codePoint - 0xAC00) % 28`을 계산한다 — 0이면 받침 없음(`"가"`), 0이
아니면 받침 있음(`"이"`). 마지막 글자가 이 범위 밖(한글이 아닌 문자,
숫자 등)이면 `"가"`를 기본값으로 돌려준다(방어적 기본값이 아니라 —
현재 로스터 5인이 전부 순수 한글 이름이므로 이 경로는 계약 테스트에서
직접 검증 대상은 아니며, 함수가 예외를 던지지 않는다는 것만 보장한다).

## 로스터 5인 검증 (research.md §5)

| 이름 | 마지막 글자 | 받침 | `particleFor()` 결과 |
| --- | --- | --- | --- |
| 금동이 | 이 | 없음 | `"가"` |
| 루이 | 이 | 없음 | `"가"` |
| 오드 | 드 | 없음 | `"가"` |
| 샤오바이 | 이 | 없음 | `"가"` |
| 모카 | 카 | 없음 | `"가"` |

**다섯 전부 "가"를 받는다** — 현재 로스터에는 받침 있는 이름이 없다.
계약 테스트는 이 다섯을 전부 검증하고, **받침 있는 이름의 "이" 분기를
검증할 별도 케이스**(로스터에 없는 가상 이름, 예: "테스트인" — 받침
있음을 의도적으로 만든 문자열)를 하나 더 둔다.

## 불변식

1. **순수 함수다.** 부작용이 없고, 같은 입력에 항상 같은 출력을 낸다.
2. **`Character`·`../models/roster`·`./persona`를 import하지 않는다**
   (원칙 III — `monologue.ts`와 같은 격리 규칙을 이 파일도 따른다).
3. **예외를 던지지 않는다.** 빈 문자열·비한글 문자에도 값을 돌려준다
   (기본값 `"가"`).
4. **`"이"`·`"가"` 둘 중 하나만 돌려준다.** 다른 조사(을/를, 은/는 등)는
   다루지 않는다 — 016의 로드 단계 문구가 요구하는 것은 주격 조사
   하나뿐이다(spec Assumptions 범위).
