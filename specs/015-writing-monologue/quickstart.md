# Quickstart: 쓰는 중 독백 검증

## 기기 없는 검증 (항상 돈다)

```
npm run test:logic   # pipeline.test.ts, on-device.test.ts, monologue.test.ts
npm run test:ui      # app/state.test.ts (writing 상태 stage 필드)
npm run lint          # tsc + 헌법 검사(monologue.ts의 import 제한)
```

**위반 주입으로 확인할 것** (AGENTS.md 「작업 습관」 관례):
- `monologue.ts`에 일부러 `import { personaOf } from "./persona"`를 추가해
  헌법 검사가 잡는지 확인한 뒤 되돌린다.
- `ProgressStage`에 `{ stage: "vision"; index: number }`처럼 숫자 필드를
  일부러 추가해 `on-device.test.ts`의 계약 테스트(정규식 `/\d/` 검사 등)가
  잡는지 확인한 뒤 되돌린다.

## 실기기 검증 (최소 1회, debug로 충분)

**★ 루이(narrative)로 검증한다.** 로드맵이 이미 경고했듯 2.4~2.6초로 끝나는
캐릭터(quiet 등)는 독백이 스쳐 지나가 Maestro의 조건부 블록이 SKIPPED로
넘어갈 위험이 크다 — 루이는 26초 이상(웜) 머물러 세 단계를 눈으로 확인하기
가장 쉽다.

### A1. 진행 단계가 순서대로 바뀐다 (User Story 1)

1. `EXPO_PUBLIC_APP_ENV=dev npx expo start --dev-client`
2. 루이(narrative)를 캐릭터로 고르고, 사진 보기를 "빠르게 봄"으로 설정한다.
3. 일기 쓰기를 시작하고 화면을 지켜본다.
4. **기대**: "그날의 기록을 확인하는 중…" → "사진을 들여다보는 중…" →
   "글을 쓰는 중…" 순서로 문구가 바뀐다. 숫자·퍼센트가 안 보인다.

### A5. 사진이 여러 장이면 사진 보기 단계 안에서 문구가 계속 바뀐다 (FR-013, FR-014)

1. 사진이 3장 이상 있는 하루를 심는다(필요하면 010 `seed:day` 도구 사용).
2. 루이(narrative)로 "빠르게 봄"을 설정하고 생성을 시작한다.
3. **기대**: "사진을 들여다보는 중…" 단계가 지속되는 동안 문구가 최소
   두 번 이상 바뀐다(예: "사진을 들여다보는 중…" → "또 한 장을 살펴보는
   중…"). 연속으로 완전히 같은 문구가 두 번 나오지 않는다. 어느 문구에도
   "첫 번째"·"두 번째" 같은 순번이 없다.

### A2. 사진 보기를 끄면 vision 문구가 안 보인다 (FR-003)

1. 사진 보기를 "보지 않음"으로 설정한다.
2. 같은 하루로 다시 생성한다.
3. **기대**: "사진을 들여다보는 중…" 문구가 한 번도 안 보인다. "확인하는
   중…" → "글을 쓰는 중…" 두 단계만 보인다.

### A3. 실패 화면 전환 후 독백이 남지 않는다 (FR-009, Edge Case)

1. 모델이 준비 안 된 캐릭터로 생성을 시도하거나, 생성 중 기기를 비행기
   모드로 전환해 실패를 유도한다.
2. **기대**: 실패 안내 화면으로 전환된 뒤 이전 독백 문구가 화면 어디에도
   남아있지 않다.

### A4. 그만두기 후 독백이 사라진다 (FR-010)

1. 생성 도중 "그만두기"를 누른다.
2. **기대**: 목록 화면으로 돌아가고, 독백 문구가 남아있지 않다(기존 007
   취소 동작 그대로).

## 확인 표

| 항목 | 방법 | 통과 |
| --- | --- | --- |
| 옵셔널 확장이 기존 계약을 안 깬다 | `npm test` 전체 | 기존 002/003/005/012 테스트 전부 그린 |
| `monologue.ts`가 로스터에 안 닿는다 | `npm run lint`(헌법 검사) | 위반 0건 |
| 진행 신호에 숫자가 없다 | 계약 테스트 + 실기기 육안 확인(A1) | 숫자·퍼센트 미노출 |
| 빠른 캐릭터에서도 화면이 안 깨진다 | quiet로 A1 반복, SKIPPED 여부 확인 | 완료 화면까지 정상 도달(User Story 2) |
| 사진 여러 장에서 문구가 계속 바뀐다 | A5, 사진 3장 이상으로 실기기 확인 | 연속 반복 없음, 순번 미노출 |
