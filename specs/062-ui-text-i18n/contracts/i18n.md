# Contract: 화면 문구 카탈로그와 언어 해석 (062)

계약 번호는 테스트 이름에 그대로 쓴다.

## 해석 — `src/i18n/resolve.ts`

```ts
resolveLanguage(detected: readonly string[] | null, supported: readonly Language[], fallback: Language): LanguageResolution
```

- **L1**: `detected === null` → `{ detected: null, chosen: fallback, matched: false }`.
- **L2**: 선호 순서대로 각 태그의 첫 마디(`-`·`_` 앞)를 소문자로 바꿔 `supported`에서 찾는다. 첫 일치를 `chosen`으로, `matched: true`.
- **L3**: 일치가 없으면 `chosen: fallback`, `matched: false`. `detected`는 입력 그대로(정렬·정규화하지 않는다).
- **L4**: 첫 마디가 빈 태그(`"-KR"`, `""`)는 건너뛴다. 던지지 않는다.
- **L5**: 순수 함수 — `new Date`·전역·모듈 상태를 읽지 않는다(소스 계약).
- 예: `["ko-KR"]`→ko·matched · `["KO"]`→ko · `["en-US","ko-KR"]`→ko·matched · `["en-US"]`→ko·unmatched · `null`→ko·unmatched ·
  (가짜 목록 `["ko","xx"]`) `["xx-YY","ko"]`→xx.

## 감지 — `src/i18n/locale-port.ts`

```ts
readDeviceLocales(): readonly string[] | null
```

- **D1**: `expo-localization`을 호출 시점에 try/catch로 `require`한다. 모듈 최상단 import가 아니다(소스 계약).
- **D2**: `getLocales()`가 던지거나, 배열이 아니거나, 빈 문자열이 아닌 `languageTag`가 하나도 없으면 `null`.
- **D3**: 돌려주는 태그는 `languageTag` 원문, 기기 선호 순서.
- **D4**: 이 파일만 `expo-localization`을 import한다(헌법 검사).

## 현재 언어 — `src/i18n/current.ts`

```ts
text(): Catalog
languageResolution(): LanguageResolution
```

- **C1**: 첫 호출에서 `readDeviceLocales()` → `resolveLanguage(…, SUPPORTED_LANGUAGES, DEFAULT_LANGUAGE)`를 **한 번** 하고 캐시한다. 두 함수가 같은 결정을 본다.
- **C2**: `text()`는 호출마다 **같은 객체**(`Object.is`)를 돌려준다(055 `currentEnvironment()` 교훈).
- **C3**: 전경 복귀·`AppState` 구독이 없다(Clarification Q1 — 소스 계약: `AppState` 참조 0).
- **C4**: `text()`를 부르는 모듈은 그것을 **모듈 최상단에서 평가하지 않는다** — 렌더·함수 안에서 부른다(소스 계약: `src/ui/`·`src/app/`·`src/schedule/`·`src/onboarding/`·`src/diary/monologue.ts`·`App.tsx`의 최상단 `text()` 평가 0건).
- **C5**: 헤드리스 태스크(`schedule/task.ts`)의 완성 알림 제목과 알림 채널 이름이 `text().notification`에서 온다.

## 카탈로그 — `src/i18n/catalogs/`

- **K1**: `type Catalog = typeof ko`. `ko`에 `as const`가 없다(소스 계약) — 다른 카탈로그가 타입을 만족할 수 있어야 한다.
- **K2**: 다른 카탈로그는 `satisfies Catalog`. 항목 하나를 빼거나 함수 인자 모양을 바꾸면 tsc 오류(타입 테스트 파일의 `@ts-expect-error`로 잠근다).
- **K3**: `CATALOGS`는 `Record<Language, Catalog>` — 지원 목록에 언어를 더하고 카탈로그를 안 넣으면 tsc 오류.
- **K4**: 카탈로그 함수는 순수하고 던지지 않는다. 판정하지 않는다(날짜가 오늘인가·권한이 있나는 부르는 쪽이 정해 인자로 준다).
- **K5**: `src/i18n/`은 `diary/prompt`·`signals/`·`inference/`·`models/`·`vision/`·`schedule/`·`ui/`·`app/`에서 **값을 import하지 않는다**. `import type`은 어디서든 허용한다(`DayDate`·`HourFormat`·`MonologueBranch` 등 — 타입은 런타임에 남지 않는다). 값 import의 예외는 한국어 카탈로그의 `diary/particle` 하나.
- **K6**: 화면 문구를 만드는 자리(`src/ui/`·`src/app/`·`src/schedule/`·`src/onboarding/`·`App.tsx`)는 `diary/particle`을 import하지 않는다(헌법 검사, FR-005).

## 경계

- **B1**: 화면 문구 소스 검사(R7) — 주석을 걷은 한글 문자열·JSX 텍스트가 `src/i18n/catalogs/` 밖이면서 허용 목록 밖이면 위반. 허용 목록의 경로는 모두 존재한다.
- **B2**: `prompt.ts`는 `src/i18n/`을 import하지 않는다 — 화면 언어가 프롬프트로 새지 않는다(FR-016).
- **B3**: 화면 계층(`src/ui/`·`src/app/`·`App.tsx`)이 신호의 `.reason`, 준비 상태 reason, pipeline detail 문자열을 화면에 그리지 않는다(R5 내부 값 확인).
- **B4**: 제품 `SUPPORTED_LANGUAGES`는 `["ko"]`이고 테스트 가짜 언어가 없다.
- **B5**: 한글 피연산자로 문구를 비교해 분기하는 코드가 없다(`.test(`·`includes(`·`===`·`startsWith(`, R8).
- **B6**: 저장 타입(`DiaryEntry`와 `preferences/` 파일 타입)의 필드 목록이 R13에서 확인한 목록과 같다 — 새 필드가 생기면 실패해 「문구를 저장하는가」를 다시 보게 한다.

## 회귀

- **G1**: 이관 전 화면 문구 리터럴 다중집합 == 이관 후 `catalogs/ko/` 리터럴 다중집합(명시한 차이: 지운 죽은 코드 `failure-text.ts` — 골든 대상 목록에 애초에 넣지 않는다, 새 진단 언어 줄).
- **G2**: 이관 전 함수 출력 골든 == 이관 후 카탈로그 함수 출력(바이트).
- **G3**: `__tests__/diary/prompt-e2sn.test.ts`·`prompt.test.ts` 무수정 통과(git diff 0줄).
- **G4**: 기존 보드 원문 대조 테스트의 기대 문자열 변경 0건.

## 시연 (언어 하나 추가)

- **X1**: 테스트 전용 `xx` 카탈로그 + 가짜 지원 목록 + 감지 `["xx-YY"]` → `languageResolution().chosen === "xx"`, 홈 화면 한 곳이 `xx` 문구로 그려진다.
- **X2**: 같은 상태에서 만든 프롬프트가 한국어 화면일 때와 바이트 동일(US4-2).
- **X3**: `xx`를 더하는 데 필요한 제품 파일 변경 0 — 테스트는 `jest.mock`으로 `languages`·`catalogs/index`·`locale-port`만 바꾼다.

## 진단 언어 줄 (FR-011b)

- **V1**: 진단 「환경」 묶음에 한 줄: 라벨 「언어」, 값 「{감지한 첫 태그} → {고른 언어 이름}」. 감지 못함이면 「모름 → {고른 언어 이름}」. 언어 이름은 카탈로그의 표(`diagnostics.languageName`)에서 온다(한국어 카탈로그: `ko` → 「한국어」).
- **V2**: 값 문자열 조립은 `diagnostics-view.ts`(순수)가 하고 화면은 문자열만 받는다(060 관례).
