## 구성

- **`src/app/target-hour.ts`(순수)** — 시 → 행 값(「오후 10시쯤」/「22시쯤」), 12시간 표기의 12시 처리(오전 12시 = 0시, 오후 12시 = 12시),
  격자 칸(12시간: 12·1–11 / 24시간: 0–23), 오전↔오후 전환 시 시 칸 유지(오후 10 → 오전 10), 미리보기 문장, 시간대 줄 「이 휴대폰의 시간대 · {city} ({gmt})」.
  `now`·형식·시간대는 인자로 받는다.
- **`src/ui/TargetHourDialog.tsx`(`6f`)** — `DismissibleDialog` 틀 + (12시간 형식만) 오전/오후 칸 + 격자 + 미리보기 + 취소/저장. 고른 값은 대화상자 로컬이고
  저장 때만 올린다. 값이 같으면 저장도 그냥 닫는다. 바깥 탭·시스템 뒤로 = 취소.
- **`src/ui/PlaceNameDialog.tsx`(`6l`)** — 칸 셋(자동·켬·끔, 설명 줄) + 지도 고지 + 취소. 누르면 바로 적용하고 닫는다. 「켬」이면 닫힌 직후 위치 권한
  요청(이미 허용이면 OS가 안 띄운다), 거부돼도 값은 「켬」.
- **`SettingsScreen`** — `diaryExtras`를 없애고 「매일 쓰는 시각」 행(토글 켜짐일 때만, 높이 0→44 · 200ms)과 「장소 이름으로 보기」 행(늘)을 props로 받는다.
- **조립(`App.tsx`)** — 저장 → 다시 예약은 기존 `settings-effects.ts`(S6). 값 보관은 T3.
- **걷는 것** — `AutoDiarySettingsScreen`·`GeocodingSettingToggle`과 그 자기 테스트(쓰는 곳이 사라진다).
