# 가상의 하루를 기기에 심는 도구 (010)

계약: [specs/010-synthetic-day-fixture/contracts/](../../specs/010-synthetic-day-fixture/contracts/)

## 이것이 무엇인가

**테스트 기기는 주머니에 들어가지 않는다.** 그래서 그 기기가 본 하루에는 볼 것이 없고,
005~009의 실기기 확인이 전부 「사진 없음 + 나머지 모름」인 하루 위에서 이뤄졌다.

이 도구는 지정한 하루에 해당하는 **사진을 기기의 사진 보관함에 심는다.**

## ⚠️ 경계 — 이 도구가 하지 않는 것

| 안 하는 것 | 근거 |
| --- | --- |
| **앱의 일부가 되기** | FR-001. `scripts/`는 번들에 들어갈 길이 없다 |
| **일기를 읽거나 쓰기** | FR-003·022, **헌법 원칙 IV**. 채점·비교·지어내기 세기가 없다 |
| **앱에 신호를 주입하기** | FR-004. 심는 것은 **입력(사진)**이지 출력(일기)이 아니다 |
| **권한을 주거나 거두기** | FR-014. 004가 가른 갈래를 흐린다 |
| **자동으로 치우기** | FR-011a. 사람이 지시할 때만 |
| **걸음·배터리·연결 심기** | FR-009. 되짚을 통로가 없다 |

**앱은 이 도구가 있었는지 모른다.** 심어진 사진을 평소와 똑같이 미디어 라이브러리에서
읽는다 — **앱 코드는 한 줄도 바뀌지 않았다**(FR-004a).

## ⚠️ 심은 하루로 품질을 결론짓지 않는다

**헌법 원칙 V**: 「합성 데이터로 모델 품질을 평가하지 않는다」.

심은 하루에서 나온 일기를 보고 「프롬프트가 좋아졌다」고 결론 내리면 위반이다. 그 하루는
우리가 만든 것이며, 우리가 기대한 답을 유도하도록 만들었을 수 있다.

**얻을 수 있는 것은 「이 경로가 도는가」이지 「출력이 좋은가」가 아니다**(FR-021).

## 쓰는 법

```
npm run seed:day -- rich 2026-08-20    # 심는다
npm run seed:list                       # 뭐가 심겨 있나
npm run seed:clear                      # 치운다 (지시할 때만)
```
